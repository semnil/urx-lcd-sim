# 作っていないもの

このシミュレーターは画面遷移と操作手順を確かめるためのもので、実機の機能そのものは持たない。
ここには、実機にある機能のうちこのシミュレーターの対象から外したものと、実機にも無いために
このシミュレーターも持たないものを挙げる。画面の一覧と実装状況は [screen-inventory.md](screen-inventory.md) が正。

## 画面

| 実機の画面 | このシミュレーターでの扱い | 理由 |
| --- | --- | --- |
| CH SETTING の Icon 選択 | CH SETTING の Icon の箱はチャンネルカラーの四角を置く。選択画面は開かない | アイコンの絵は再現が難しいため描かない |
| Simple Mode 全体 (Setup Assistant、ユースケース選択、Simple の HOME とチャンネルビュー) | Operation Mode に Simple Mode のカードは並ぶが、選べない項目として描く | このシミュレーターの範囲外 |
| Cubase シリーズ専用画面 (Input settings / Hardware settings / MixKey channel editor) | 画面自体が無い | このシミュレーターの範囲外 |
| Initialize All Memories (工場出荷状態への初期化) | 画面自体が無い。画面の外にある [Reset the unit] が同じことをする | このシミュレーターの範囲外 |

## コントロール

| 実機のコントロール | このシミュレーターでの扱い | 理由 |
| --- | --- | --- |
| [AUTO] (チャンネルビューのヘッドアンプ) | 実機と同じ位置に描くが、押せない | 入切の設定ではなくオートゲインを走らせるボタンで、走らせる相手が無い |
| [Auto Gain] (INPUT 画面) | 同上 | 同上 |
| LANGUAGE の 日本語 / 簡体中文 | 選べない項目として描く | 画面の文言が英語しか無い |
| EFFECT TYPE のエフェクトの絵 | ボタンにはエフェクトの名前だけを置く | エフェクトの絵は再現が難しいため描かない |

## 動くが、実機と同じ働きはしないもの

- **音声を扱わない。** メーターは合成信号で、チャンネルのフェーダー、オシレーターの送り先、
  CUE に入れたチャンネル、MIC/LINE の端子の A.Gain に合わせて動く。A.Gain を +44 dB まで上げると
  入力がクリップし始め、Clip Safe はそれを見て作動する (screen-inventory.md「チャンネルビューの
  ヘッドアンプ」)。録音したファイルは長さと大きさを持つだけで、音は入らない。
- **Clip Safe の下げ始め。** 実機は、手を叩いてクリップさせたとき、最後のクリップの約 2 秒後から入力を
  下げた (URX44V、2026-09-22 に実機で確認)。このシミュレーターはクリップを読み取った直後から下げる。
- **M.B.Comp の 1-knob は行を預かるだけ。** 入にすると帯域の Threshold / Ratio / Gain / Attack と
  Release と 2 つの Xover は読みだけを残して操作を受けず ([Bypass] はページから消え)、実機と同じく
  その中で操作できるのは Out Gain だけ。ただし 1-knob Level に合わせて値を計算し直さない。
- **SSMCS の Morphing と Sweet Spot Data は自分の値だけを動かす。** 実機はどちらを動かしても
  ストリップの連続値 (コンプの Attack / Release / Ratio / Knee、サイドチェーンの Q / Freq. /
  Gain、EQ 3 バンドの Freq. / Gain と MID の Q、Out Gain) を計算し直すが、その計算の中身は
  分かっていないので、このシミュレーターは値を動かさない。押せない面にもしない — 実機は
  計算した後もその行を操作させるため。`01 Basic` の値だけは分かっており、出荷時の値がそれ。
- **microSD のカードは画面の中で抜き差しする。** 取り出しボタンは実機と同じダイアログを出す。実機のダイアログは
  数秒で自ら閉じ、[OK] に触れても何も起きない (カードが抜かれたことは本体が検出する)。このシミュレーターは
  ダイアログを閉じずに待ち、その [OK] でカードを抜いたことにする。カードが無い microSD のトップで
  `Not inserted microSD card` に触れると、このシミュレーター独自の `Simulate inserting the microSD card?`
  ([Cancel] / [OK]) を出し、[OK] で同じカードを入れ直したことにする。
- **COMP の 1-knob も行を預かるだけ。** 入のあいだ実機は Threshold / Ratio / Gain / Knee を
  Level から計算し直すが、その計算の中身は分かっていない。このシミュレーターは実機と同じく
  他の行を操作させないが、値は動かさない。
- **1-knob EQ の Intensity の 0.1 dB。** 実機は 1-knob を入れたときのゲインに Level / 50 を掛けて 0.1 dB に揃えるが、
  一部の基準と Level の組でそれより 0.1 dB 高い値を出す (基準 +12.3 dB の Level 1・14・27・38% で 0.3 / 3.5 / 6.7 / 9.4 dB。
  読む時刻にも Level を動かす向きにもよらない。URX44V、2026-09-22 に実機で確認)。どの組で起きるかの規則は分かっていないので、
  このシミュレーターは式どおりの値にする。
- **COMP の Auto Makeup は Gain を預かるだけ。** 入にすると Gain の区画は読み出すだけになるが、
  実機が算出する値は分かっていないので、表示は入にする前の値のまま。

## 実機にも無いもの

実機が持たない働きは、このシミュレーターも持たない。

- **夏時間。** 実機の時計は [Time Zone] の都市の標準時を一年を通して表示し、夏時間に切り替わらない
  (9 月に Tokyo の 21:15 が London では 12:15、実機で確認済み)。このシミュレーターも同じく標準時で
  表示するので、夏時間の期間中は、夏時間を持つ地域のコンピューターの時計と 1 時間ずれる。
- **+48V と HI-Z の排他。** ユーザーガイドは INPUT 画面の [+48V] の説明で「The phantom power supply
  and HI-Z cannot be turned on at the same time.」とするが、実機は [+48V] を入れたまま [HI-Z] を押しても、
  [HI-Z] を入れたまま [+48V] を押しても、[+48V] と [HI-Z] がどちらも入になる (URX44V、2026-09-22 に
  実機で確認)。このシミュレーターも 2 つを同時に入れられる。
- **USB Storage Mode 中のメニューの制限。** ユーザーガイドは「USB Storage Mode button」の NOTE で「You cannot access any
  other menus from this product while USB Storage Mode is on.」とするが、実機はモードを入れたまま HOME を押すと HOME 画面へ
  移り、SETUP・MONITOR・チャンネルの画面も開く (URX44V、2026-09-22 に実機で確認)。このシミュレーターも移動を制限しない。
  microSD 画面の [Recorder]・[Save/Load]・[Tools] はモードのあいだ使えない (p078-1)。
- **ステレオリンクしたチャンネルのステレオの LEVEL メーター。** ユーザーガイドは p97 の LEVEL meter の説明で「Stereo
  channels and channels that are stereo-linked are shown with a stereo meter.」とするが、実機はステレオリンクした
  ペアのチャンネルを選んでも、チャンネルビューのメインエリアの LEVEL メーターは 1 本で、HOME もチャンネルごとに 1 本
  (URX44V、2026-09-26 に実機で確認)。このシミュレーターもそこは 1 本で描く。

## 実機へは書かない

シミュレーターは実機のプロトコルを持たない。パスと実機のアドレスの対応表 (`BindingTable`) は
空の状態で配布され、束縛されていないパスへの書き込みは拒否される。詳細は
[architecture.md](architecture.md)「パラメータのアドレス指定」にある。
