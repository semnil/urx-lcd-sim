# 画面インベントリ

URX44V/44/22 ユーザーガイド (英語版 revision D0) が載せている LCD 画面の一覧と、シミュレーターでの
実装状況。「参照」列はユーザーガイドのページ番号。文中の `p045-1` や `wide/p040-2` はそのページから
抽出したキャプチャのファイルで、置き場所と命名は [design-tokens.md の「採取方法」](design-tokens.md#採取方法)
にある (`reference/` は git 管理外。再生成は `node scripts/extract-ug-screens.mjs --pdf <ユーザーガイド PDF>`)。

「画面 ID」は `ScreenRegistry` に登録されている識別子で、`src/screens/index.ts` の
`buildRegistry()` が唯一の登録場所。

画面のあいだの行き来は [screen-map.md](screen-map.md) が図で持つ。

## 作らないもの

ユーザーガイドに載っているがシミュレーターでは作らないもの。

コントロールでは [AUTO] (チャンネルビューのヘッドアンプ) と [Auto Gain] (INPUT 画面) の 2 つ。
どちらも入切の設定ではなくオートゲインを走らせるボタンで、走らせる相手が無い。実機の配置を保つため
描いたうえで、Operation Mode の選べない Simple Mode のカードと同じ面・字・帯
(`--surface-disabled` / `--menu-text-disabled` / `--btn-bevel-disabled`) にして押せなくする。
この 2 つは帯を角の地図 (`--pb-band`) 経由で描くので、そこにも渡す — 面より明るい帯が残ると
ボタンに見えなくなる。触りはボタン自身が受け止める (`pointer-events: auto`) — 使えないボタンの
共通の規則は触りを透かすが、[AUTO] の下のセルは INPUT 画面を開くので、透かすとボタンを押した
つもりで画面が変わる。角は実測の消灯の系統と同じ刻み (18% / 65% / 94%、足元は 0 / 60% / 90%) を
この面と帯に当てて作る。値を持たないので、ストアにも置かない。

| 画面 | 参照 | 理由 |
| --- | --- | --- |
| CH SETTING の Icon 選択 | p92 | アイコンの絵は再現が難しいため描かない |
| Simple Mode 全体 (Setup Assistant、ユースケース選択、Simple の HOME とチャンネルビュー) | p117-132 | このシミュレーターの範囲外 |
| Cubase シリーズ専用画面 (Input settings / Hardware settings / MixKey channel editor) | p159-168 | このシミュレーターの範囲外 |
| Initialize All Memories (工場出荷状態への初期化) | p169 | このシミュレーターの範囲外 |

## チャンネルビューのヘッドアンプ

アナログのヘッドアンプ (`A.Gain` -8..+70 dB、HI-Z 入は -8..+40 dB・[+48V]・[HI-Z]・[Clip Safe]) は MIC/LINE の端子に
付き、チャンネルには付かない。入力ソースが MIC/LINE のチャンネルは、その端子のヘッドアンプを出す。
モノラルチャンネルは組の中の自分の位置の端子 (CH 1/2 を MIC/LINE 3/4 にすると CH 1 が 3、CH 2 が 4)、
ステレオチャンネルは表示中の側の端子。同じ端子に載った 2 つのチャンネルは同じ値を出し、どちらで
回しても入切しても両方が動く。値は端子と同じ番号のモノラルチャンネルの下に置く。A.Gain・+48V・HI-Z・
Clip Safe は、同じ端子に載った CH 1 と CH 3 で片方の変更がもう片方に出ることを実機で確かめた (URX44V。A.Gain と
HI-Z は 2026-09-21、+48V と Clip Safe は 2026-09-22)。

それ以外のソースでは、チャンネルはそのソースの `D.Gain` (-24..+24 dB) を出す。D.Gain は入力
ソースに付く値で、チャンネルには付かない。同じソースに載ったチャンネルは、モノラルでもステレオ
でも同じ D.Gain を出し、どれで回しても全部が動く (モノラルの組の 2 チャンネルは、`MONO x 2` でも
別々の値にならない)。ソースはどのチャンネルも載っていないあいだも値を覚えていて、戻すとその値に
戻る。工場値は USB MAIN A / B / C と USB SUB が -14、それ以外のソースが 0。置き場と工場値は
`src/model/source-gain.ts`。ソースが `None` のあいだはゲインを出さない (INPUT 画面の左のパネルは
レベルバーだけ)。ソースを行き来しても A.Gain はそのまま残る。アナログのヘッドアンプに付くもの — 状態パネルの
+48V と HI-Z、AUTO / SAFE、INPUT 画面の [+48V]・[HI-Z]・[Clip Safe]・[Auto Gain]、HOME の
ストリップの +48V の印 — もそのあいだは消える (ユーザーガイド「INPUT screen」の NOTE と各ボタンの
説明)。チャンネルビューの [SAFE] は端子の Clip Safe で、INPUT 画面の [Clip Safe] と同じスイッチ。
判定は `src/screens/head-amp.ts` の `micLineConnector()` 1 箇所。

ヘッドアンプは 1 dB 刻みで、値は整数に丸めて 0 より大きいときだけ `+` を付ける
(`+14` / `0` / `-8`、読み出しバーは `+14dB`)。フェーダーは従来どおり小数第 2 位まで。

ダイナミクスのしきい値とレンジは整数 dB (`-33dB` / `-20dB`、p099-1 / p103-1)、メイクアップ
ゲインは小数第 1 位 (`18.0dB`)。時間はパネルの値ボックスが `34.58m`、読み出しバーが
`34.58ms` と、同じ値でも単位の綴りが違う (p099-1 / p103-1)。1 秒を超えて動く時間は
1000 ms から秒に変わる (`4.8s`、p114-1)。単位の前に空白は入れない。周波数は小数第 1 位で、
1 kHz からは kHz に切り替わり、キャプションを持つ値ボックスでは単位を付けない
(`80.0` と `80.0Hz`、p100-1)。

HI-Z は端子が持つもので、MIC/LINE の端子全部ではない。URX44 と URX44V は MIC/LINE 3・4、
URX22 は MIC/LINE 2。それを持つ端子に載っていないチャンネルでは、ヘッドアンプの状態パネルの
そのマスが空き、INPUT 画面のボタンも出ない。HI-Z が入っているあいだ、その端子の A.Gain は
-8..+40 dB になる。+40 dB を超えている A.Gain は HI-Z を入れると +40 dB に下がり、HI-Z を切っても
+40 dB のまま残る (URX44V で実機確認、2026-09-22)。押し下げは `src/screens/head-amp.ts` の
`hiZWriteRule()`。つまみの向きは [design-tokens.md の「ストリップのロータリー」](design-tokens.md#ストリップのロータリー)。

Clip Safe が入っている端子の入力がクリップすると、実機は入力を約 23 dB 下げて約 5 秒で戻し、A.Gain の値と
つまみは下がらない (URX44V で実機確認、2026-09-22)。シミュレーターは、読み取った入力がメーターのクリップの
印の点く 0 dB に届くとその読み取りではクリップを見せ、その後の入力を 23 dB 下げて、最後のクリップから 5 秒で
戻す。下げているあいだも 0 dB に届けばクリップとして数え直し、戻した直後にまた届けばそのまま下げ直す。
作動中は INPUT 画面の [Clip Safe] とチャンネルビューの [SAFE] が点灯のシアンから GATE の点灯と同じオレンジに
変わる。オレンジの色、色が変わるのが作動中であること、クリップが続くあいだ作動し続けることは操作者の指定。
置き場は `src/screens/meters.ts` の `clipSafe()`。

合成信号では、MIC/LINE の端子の入力は A.Gain と同じだけ上がり、A.Gain +44 dB で山が 0 dB に届き始める
(工場出荷の -8 dB では平均 -58 dB)。同じ端子に載ったチャンネルは同じ入力を読む。INPUT 画面のメーター
2 本とチャンネルビューの入力部のメーターはフェーダーより前を読み、フェーダーと [ON] では動かない
(ユーザーガイド「INPUT screen」の Input meter の説明)。

単位の前の空白は図が割れている (p114-1 は `-69 dB`、p099-1 と p104-1 は `-33dB`)。実機は
空白なしで統一されている。

## ステレオリンク (Signal Type)

CH SETTING の `Signal Type` は 1 チャンネルではなく隣り合うモノラルチャンネルのペア
(CH 1 と CH 2、CH 3 と CH 4) が持つ設定で、`STEREO` (ステレオリンク) と `MONO x 2`
(独立した 2 チャンネル) から選ぶ。どちらのチャンネルの画面で切り替えても両方に書き込む。
判定と書き込みは `src/screens/stereo-link.ts` 1 箇所。

- HOME はペアの PAN スライダーの間、2 つのストリップの隙間にハートマークを描く。マークは
  ペアの右側のチャンネルが描き、相方が隣に並んでいるバンクでだけ出す (ユーザーガイド p48 の
  NOTE、キャプチャは p045-1)。マークは黒い円 (直径 16px) に白いハート (10x10px) で、隙間の
  中心と PAN スライダーの中心が交わる位置に立つ。
- 選択中のストリップの枠がマークに届く高さでは、枠は途切れずマークの外周を円弧で回る
  (キャプチャは p047-1)。円弧は選択されている側だけに出て、直線の枠の外縁まで
  (隙間の半分 − 枠の幅) 描く。切り欠きが枠から食う範囲を全て覆うための位置。円弧は直線の
  枠と同じく縁の上に乗るので、帯は切り欠きの縁をまたぐ (自分の幅の半分だけ外へ出す)。
  ハートは円弧の幅だけ小さくなる。枠自体は [HOME ストリップの構成](#home-ストリップの構成) を参照。
- ペアになってもメーターはチャンネルごとに 1 本ずつで、HOME もチャンネルビューも変わらない。
  ユーザーガイド p97 の LEVEL meter は「ステレオリンクされたチャンネルはステレオメーター」と
  書いているが、実機はチャンネルごとに 1 本。
- `STEREO` のときだけ CH SETTING の Signal Type の下に `PAN` / `BAL` ボタンが出る
  (キャプチャは p093-1)。`BAL` を選ぶとチャンネルビューの `PAN` が `BALANCE` に変わり、
  HOME のスライダーも同じ値を指す。この選択もペアの両方に書く。ペアの BALANCE は 1 つで、
  若い方のチャンネル (CH 1 と CH 2 なら `ch.ch1.balance`) が持ち、両方の画面が同じ値を出す。
  `PAN` のときは各チャンネルが自分の `pan` を持つ。
- `STEREO` にするとペアは `BAL` で入る (p093-1)。3 つの遷移 — `STEREO` 化・`PAN`/`BAL` の
  切替・`STEREO` 解除 — はそのたびに両チャンネルの位置を置き直す。`PAN` は若い番号の
  チャンネルを左端 (L63)、もう一方を右端 (R63) へ、`BAL` と解除は両方を中央 (C) へ置く。
  置き直す先はチャンネル自身の位置と、そのチャンネルの各 Send の位置の両方。
- リンク中のペアは 1 組の値を持つ。片方への書き込みはもう片方へ届き、リンクした時点で
  若い番号のチャンネルの値がもう一方へ写る。解除は何も戻さない。各メンバーが自分の値を
  保つのは、ヘッドアンプ (A.Gain・Clip Safe・Φ・+48V・Hi-Z)・入力ソース・名前・色・CUE と、
  `BAL` 以外での位置。Signal Type と `PAN`/`BAL` はペアの値で両方へ書き、インサートと
  BALANCE は若い番号のチャンネルが持つ形のまま。

`src/screens/stereo-link.test.ts` が振る舞いを、`src/style/columns.test.ts` の
「the stereo-link mark between two strips」がマークの位置を固定している。

## MIX バスの BUS Type と Pan Link

MIX バスの CH SETTING は Color / Icon / Name の下に 2 つを出す (p093-2)。`BUS Type` は
Signal Type と同じ 3 行目に 136px のプルダウン (箱は p093-2 の x77..212 / y157..196)、
`Pan Link` は 4 行目、`PAN` / `BAL` と同じ位置に 86px のボタン (x317..402 / y209..248)。
2 行目は空く。他のバスとチャンネルはどちらも持たない。

- `BUS Type` は `VARI` (送りごとに変えられるレベル) と `FIXED` (固定レベル) の 2 択で、
  出荷時は `VARI`。一覧は箱の下に開き、`FIXED` の面が画面の下端に届く。
- 型を取るとそのバスへの送りが全て初期化される — レベルは下端へ、スイッチは取った型が決める
  側へ (`FIXED` は切、`VARI` は入)。型を戻すともう一度初期化されるだけで、元の値は戻らない。
- `FIXED` のバスへの送りは、SEND TO のセルから [PRE] と定位スライダーと `Bal` が消え、
  レベルのノブも何も持たない。HOME の読み出しは値を出したまま回らなくなる。消えた
  コントロールの場所はそのまま空けておくので、セルの他の行は動かない。
- `Pan Link` はそのバスへの各送りの定位を、送り元チャンネル自身の位置に追従させる。入の
  あいだ行の名前は `Bal` から `PAN` に変わり、送り元の値を読み出すだけになる。送り自身の
  定位は残っていて、切ると戻る。
- `Pan Link` が働くのは `VARI` のときだけ。`FIXED` のあいだボタンは同じ場所に残り、押せない。
  値は保たれる。

判定は `src/screens/mix-bus.ts` 1 箇所で、`src/screens/mix-bus.test.ts` が固定している。

## ノブ読み出しバー

画面下端のバーはメインエリアと同じ左端 (x2) からサイドレールの左端まで、420px 届く
(p113-1 / p115-1 の実測)。3 本の区切り線は、隣のストリップどうしの隙間 (x105-106 /
x211-212 / x317-318) に立つので、ストリップを選ぶとその白い枠と区切り線が縦に並ぶ。
中央の 2 セルはストリップ 1 本 + 隙間 1 つ分 (98 + 8) の幅で、両端のセルはそこからバーの端まで。

バーと右端のノブ切り替えボタンは同じ高さ (39px) で上端を揃え、メインエリアはその上端で終わる。
ボタンは幅 52px、中のノブ字形は 20px で、ボタンの中心より少し下に置く。ラベル帯の文字はバーの
色に寄せた濃い色 (`--readout-label` / `--accent-udk-label`) で、黒ではない。

USER DEFINED KNOBS モードでは各セルが、割り当てたパラメータの値と、その短い名前を表示する
(p038-4: `-4.00` / `Monitor 1`、`-14.0dB` / `OSC Level`)。短い名前・カードの 3 行・動かす
パラメータは `src/model/udk.ts` の表が持つ。割り当ての無いノブは値の位置に `---` を出す
(実機で確認済み)。出荷時の割り当ては、バンク 1 が A = Phones 1 Level・B = Phones 2 Level、バンク 2 が
A = Brightness Screen・D = Oscillator Level、バンク 3 が A = Monitor 1 Level・B = Monitor 2 Level で、残りのノブと
バンク 4 は割り当てが無い。表示するバンクは 1。ページ番号の丸 (直径 26px) は
バーの上端にまたがり、中央の区切り線の上に立つ。両端のページ送りの山形はバーの面と同じ紫で、
字形が em に対して小さいぶんフォントサイズを大きく取る。
パラメータが 4 つを超える画面のページ送りは、8x12 の塗りの山形を描く (p103-1 の x408..415 / y258..269)。

## 入切ボタンの名前

入切を持つボタンの名前は、入っているか切れているかで太さを変えない。状態を示すのは面の色だけ。
入切のスイッチは名前を通常の太さで置く: [ON] / [CUE] / [PRE] (p047-1 の ON と CUE)、AUTO / SAFE、INPUT のフラグ、
バンクの選択肢、ブロックを入切するブロック名の箱。[1-knob] の名前は太字より一段軽い 600 (p099-1・p104-1・p106-1)、
サンプリング周波数のボタンは太字。何も入切しないブロック名の箱 (INPUT・CH SETTING・SEND TO・FX1 / FX2) と
HOME のストリップのインジケーターのバッジは太字。

点灯したシアンの面の上の名前の色は 3 通り。[ON] / [CUE] / [PRE] や HDCP の [Enable] のような入切のスイッチは
`--text-inverse`、選んだ選択肢は `--ink-on-lit`、MONITOR の [CUE Interrupt] / [MONO] と SCENE LIST の点灯した
バンクは `--surface`。どの面がどれに当たるかは [design-tokens.md](design-tokens.md) の各トークンの行にある。

## [ON] / [CUE] / [PRE] スイッチ

3 つは同じコントロールで、HOME のストリップ・チャンネルビュー・SEND TO・OSCILLATOR のどこでも同じ寸法で
描く: 40x40、角の R は 3px、下 4px は帯、ラベルは帯の上の面の中心に 13px。点灯は `--accent-on` に
`--switch-band-lit` の帯、消灯は ON・CUE・PRE とも淡色の `--accent-cue` に不透明な `--switch-band` (156,150,156)
の帯 (p047-1 の CUE の下 y204..207)。`btn-switch` が寸法を、`btn-on` / `btn-cue` / `btn-pre` が色を持つ。
OSCILLATOR の [ON] は出力の沈んだパネルに x350..389 / y99..138 で立ち、角をそのパネルの上で丸める (p070-1)。

## ノブ読み出しバーの操作

実機ではバーは読み出しで、値は下の物理ノブが回す。ここには物理ノブが無いので、値が入っている
区画そのものがノブになる (ドラッグ・ホイール・矢印キー)。空の区画は何も回さない。USER DEFINED KNOBS モードでも同じで、
割り当てのある区画はそのパラメータを回し、`---` の区画は何も回さない。1-knob が入の画面では USER DEFINED KNOBS の区画も
回らない (2026-09-24 操作者確認: CH 1 の EQ 画面で 1-knob を入にすると、A の Phones 1 は回らない)。

区画は 4 つなので、画面が 5 つ以上のパラメータを渡したときは 4 つずつに分けて表示し、続きが
ある側のラベル帯の端に `‹` / `›` を出す (p099-1 の COMP)。押すと次の 4 つに入れ替わる。画面が
変わると先頭のページに戻る。

## チャンネルビューのヘッドアンプ列

列 (x2..101、y50..227) は上から名前、値ボックスとノブ、その右の入力メーター、ヘッドアンプの
状態パネル、AUTO / SAFE。実測 (p094-1): 値ボックス x12..55 / y77..98、ノブ 38x38 / y103..140、
メーター x71..74 / y78..133、状態パネル x6..97 / y141..186、AUTO と SAFE が 44x24 で y194。
AUTO と SAFE の名前は左右の余白を取らず、面の中央に置く (p090-1 の AUTO は x11..43)。

入力メーターはどのストリップでも同じ位置に立つ。ヘッドアンプを持たないバス (FX・MIX・STEREO・
STREAMING) は名前も値もノブも状態パネルも AUTO / SAFE も持たず、メーターだけが残る (p098-2)。
この列を押すと INPUT 画面が開く。バスで開くのは STREAMING だけで、他のバスは入力ソースを持たない。
名前の行と値・ノブの列は空のまま場所を取るので、バスのメーターも x71..74 / y78..133 に立つ (p098-2)。
入力ソースが `None` のチャンネルも同じで、状態パネルも y141 から動かない。

状態パネルは 2 列 2 行で、モノラルチャンネルは +48V・Φ / HPF・HI-Z。入力ソースが MIC/LINE で
ないときは +48V と HI-Z のマスが空く。文字はキャプションと同じ 13px。点いた印はその項目のボタンと
同じ色で、+48V は赤、Φ はオレンジ、HPF と HI-Z はシアン。HOME のストリップも同じで、+48V が赤、
Φ がオレンジ、HPF がシアン、INS FX の印がそのボタンのシアン。

Φ は字でなく 10x11 の絵で描き、HOME のストリップの印、チャンネルビューの印、INPUT の [Φ] ボタンで同じ絵を使う。
高さ 7 の輪を幅 2 の縦棒が貫き、上下に 2px ずつ突き出る (p047-1、p090-1 の y151..161、p100-1 の y113..123。URX44V で操作者確認、2026-09-22)。

ステレオチャンネルの状態パネルは、MIC/LINE 以外のソースでは上段右のマスの Φ だけで、上段左と
下段は空く (p094-7 は x69..79 / y152..161、p098-1 は x69..78 / y151..161)。MIC/LINE の端子に
載っているあいだは上段左に +48V が入り、HI-Z を持つ端子なら下段右に HI-Z が入る。下段左は
空いたまま (p094-5・p094-6)。ステレオチャンネルは 2 つの側を別々に
反転し、画面は一度に片側を出す。Φ の印はその側が反転しているあいだ点き、側は `‹` `›` と
HOME の名前欄が選ぶ。HOME のストリップの印も同じ側を出す (p048-2 は x31..40 / y98..108 で、
行の右半分は空)。

処理ブロックの名前 (GATE / COMP / EQ / INS FX / DUCKER / DELAY) はラベルではなくスイッチで、
押すとそのブロックが入切する (60x20、下端 3px は影の帯、ブロック上端から 7px)。札の角は 4 画素にわたって丸め、上の角は面の色の 3 つの混色、
下の角は帯の上の 3 つの混色で描く。帯の色は面ごとに決まっていて、消灯 `--badge-band-off`、GATE と DUCKER `--badge-band-gate`、COMP
`--badge-band-comp`、EQ `--badge-band-eq`、DELAY と INS FX `--badge-band-fx` (p090-1、p098-1、p098-2)。札はブロックの左端から 14px に
立ち、GATE と DUCKER だけは 13px (同じ図)。消灯は淡色
`--badge-off`、点灯はそのブロックの色で、名前は面に対して黒 (COMP だけ白)。つまみで回す値を持つブロックは、札以外の
部分に触れた 1 回目でフォーカスを取り、2 回目でそのブロックの画面を開く。GATE・COMP・DUCKER はしきい値、DELAY は時間、
1-knob がオンの COMP と EQ は効き具合を回す。1-knob がオフの EQ と INS FX は 1 回目で画面を開く。
フォーカスを取るだけの 1 回目はパネルを沈めず、枠が出るだけにする。画面を開く触りは沈む。

ブロックの中身は値ボックス (44x22) の下に、GATE と DUCKER が 14px のランプ 3 つ (間隔 5px)、COMP が
68x4 のバー 2 本 (入力レベルとリダクション) にしきい値の白い縦線、EQ が 78x42 のパネルに縦
3 本・横 1 本の罫線とカーブ (カーブは枠の左右の端まで届く 2 行の線で、上の行が `--eq-line`、下の行が
`--eq-thumb-line`、p098-1 の y105..106 / x302..379)、INS FX がエフェクト名。DELAY の値ボックスは 60x22 で、ランプの行の高さに置く (p098-2 の x405..464 /
y92..113)。COMP の値ボックスは中央から 2px 右、バーは 1px 右で、どちらも GATE より 1px 高い (p090-1 の x227..270 / y82..103、
バーは y110..113 / y119..122)。しきい値の線は両方のバーから 3px はみ出す (y107..125)。

1-knob がオンのあいだ、COMP の値ボックスは効き具合をパーセントで示し、左に丸囲みの 1 を置き、バーにしきい値の線を
引かず、フォーカスの有無に関わらず塗りを `--accent-focus-fill` にする (p096-2 の x209..224 / y86..100)。EQ はパネルの左上に丸囲みの 1、右上に効き具合を置く
(p096-4 の x305..320 / y87..101 と x350..376 / y89..98)。カーブとその下の面は、フォーカスの有無に関わらず
`--eq-focus-edge`・`--eq-focus-line`・`--eq-focus-fill` にする。

GATE のランプは入力レベルをしきい値と比べて点く (p95): 下回っているあいだは中央が黄、上回ると
右が緑、ゲインリダクションが RANGE に達して完全に閉じていると左が赤。GATE が切のときは
どれも点かない。

DUCKER が聴ける先は入力チャンネル全部 (モノラル・ステレオとも) と STEREO・MIX 1・MIX 2 の
3 バス。一覧はチャンネルを番号だけで名乗り (`1`・`5/6`)、ステレオバスを `ST`、MIX バスを
自分の名前で出す。箱の側はチャンネル自身の名前 (`CH 1`) を出す。一覧はシートではなく、
箱の下に開く 3 行 8 列のパネルで、モノラルチャンネルが 1 行目、ステレオチャンネルが 2 行目、
その行の右端 (8 列目) に `ST`、3 行目に MIX が並ぶ。
DUCKER のランプは Ducker Source に選んだチャンネルのレベルをしきい値と比べて点く (p98): しきい値
以下のあいだは右が緑 (絞っていない)、上回ると中央が黄 (絞っている途中)、しきい値より RANGE の幅
以上上回ると左が赤 (RANGE まで絞りきった)。DUCKER が切のときはどれも点かない。

SEND TO のボタンは 86x38 で、面は `--surface-btn`、下端 3px が影の帯。

## チャンネル画面のツールバー

`‹ / チャンネル名 / ›` を左端に置く (p099-1 実測)。矢印は 40x40 (面 37px + 下端 3px の影の帯) で、
山形は 7x12 の箱の端まで届く (p090-1 の x19..25 / y15..26)。名前の 1 行目は通常の太さ (p098-2)。ボタンは
間隔 4px、面は `--surface`。名前の箱は下端 3px がそのチャンネルの色で、面は同じ `--surface`。

アイコン列の帯は左と下に 2px の罫 (`--toolbar-edge`) を持ち、左下の角は実機の画素の並び (`--toolbar-corner-*`)
で描く。SETUP の歯車、microSD の SD カード、MONITOR のヘッドホンは画素を覆い率 4 段 (1/4 刻み) で描く (p047-1 の歯車 x308..329 / y10..31、SD カード x353..372 / y10..31、ヘッドホン x398..415 / y11..30)。帯の幅は載るアイコンで決まる: HOME とチャンネルビューは x295..479 で、HOME の手前の区切りは 1px の
`--toolbar-sep-home`。戻る矢印のある画面は x384..479 で、区切りは 2px の `--toolbar-sep` とその上下 1 行の
`--toolbar-sep-end`。HOME だけを載せる画面 (MONITOR・SCENE・SETUP・microSD) は x432..479 で、左の罫が
区切りの位置に立つ。シートの戻るボタンの左下の角も同じ描き方で、色は `--sheet-back-corner-*`。

箱の幅は画面で変わる: チャンネルビューは 132px、そこからさらに下りた画面 (COMP・GATE・INPUT
など) は 53px。アイコンは箱の左端から 15px の位置に固定で、狭い箱では名前がその上に重なる。

複製マーク (10x10、`--chip-mark`) は名前の右上、箱の角から 5px 内側に立つ。チャンネル・バスの
詳細画面には出るが、そこからさらに下りた画面 (COMP・EQ など) と CH SETTING (p092-1・p093-2) には出ない。
STREAMING の詳細画面も複製マークで、図 p098-6 が同じ位置に描く四角の中の鉛筆は実機と違う (操作者確認)。
CH SETTING の Icon の箱には、チップと同じ単色の四角をアイコンの代わりに置く (x221..234 / y69..82)。

チャンネルカラーは名前の背面に置く。狭い箱では名前がその上に重なる。箱に入りきらない名前は
箱で切る。隣のボタンの上へは出さない。

`‹` と `›` はチャンネルを 1 つずつ送るだけで、画面は変わらない。送る元は画面が描いているチャンネルで、
一覧の端で反対の端へ回る。モノラルの入力は 1 本が 1 チャンネル、それ以外のストリップは 2 チャンネルで、URX44V では CH 1 … CH 12、
FX 1 L、FX 1 R、FX 2 L、FX 2 R、MIX 1 L、MIX 1 R、MIX 2 L、MIX 2 R、STEREO L、STEREO R、STREAMING L、STREAMING R の順に
送る。名前の 1 行目は表示中のチャンネルで、ステレオの入力は `CH 6` のように番号 1 つ、それ以外は L / R を付ける。狭い箱では
STEREO を `ST`、STREAMING を `STR` と書く。2 行目はストリップに付けた名前で、どちらのチャンネルでも同じ。2 チャンネルの
ストリップは、ゲインの列のメーターを表示中のチャンネルの 1 本だけにする。名前の箱は CH SETTING を開くが、CH SETTING を表示しているあいだは
何も開かない。

画面名は折り返さない。

ブロックの名前 (COMP / GATE / EQ / DUCKER / DELAY / INS FX) はツールバーの中ほど、x254 から
幅 116、高さ 40 (面 37px + 下端 3px の影の帯) の箱に立つ (p103-1・p099-1・p106-1)。右端は、ツールバー
右側の部品が始まる x384 の 14px 手前。画面の中心ではなく決まった位置で、
消灯は `--badge-title-off`、点灯はそのブロックの色。押すとブロックが入切する。角は 4 画素にわたって
丸め、上の角は面の色の 3 つの混色とその内側にもう 1 つ、下の角は帯の上の 3 つの混色で描く。混色は
点灯する色ごとに決まっている。名前は箱ではなく影の帯を
除いた面の中心に置き、文字はこの箱だけの大きさ (`--fs-2xl`)。点灯した EQ の箱は左端に、
5 つの点 (直径 8px) を 2px の線で結んだカーブを `--eq-badge-curve` で描く (p106-1 の x254..297 / y8..34、
最初の点は箱の端で切れる)。消灯した EQ の箱のカーブは、グラフのつまみの輪と同じ `--handle-ring` で描く。

何も入切しないチャンネル画面 (CH SETTING・INPUT・SEND TO) も同じ高さの箱で自分の名前を出す。
箱はどれも x254 から 116px。いちばん長い CH SETTING の名前も 112px で、箱の内側に左右 2px を残す
(p092-1 の x256..367)。面は
`--surface-sunken`、文字は白、影の帯は無く押せない (p092-1 / p100-1 / p116-1)。ツールバーの
アイコンから開く系統の画面 (SETUP・MONITOR・microSD とその下) は箱を持たず、文字だけを中央に
置く (p056-1〜p078-1)。

複製マークを p099-1 が描かないのは、詳細画面の一階層先には出ないため。p094-1 では他の線と
重なって見えにくいが出ている。

## ダイナミクスの 3 画面 (GATE / COMP / DUCKER)

3 画面は同じ枠を使う (p099-1 / p103-1 / p114-1 実測)。左にカーブのパネル (x21..220 / y51..223、
面 `--graph-bg`、1px の枠 `--surface`)、その右に 6px のゲインリダクションバー
(x228..233 / y118..225)、右端に IN / OUT メーター (x430..473、バー 6px、同メーター内 4px、
メーター間 12px、6x6 のクリップ表示、クリップとバーの間 3px、バー本体 y127..225、バーの両端は
実機の角の中間色で 3 行ずつ描く)。バーの寸法は HOME の STEREO/CUE メーターと共有する。
メーターのバーはストリップのチャンネル数だけ引く。

リダクションバーはその画面のブロックが押さえている量を読む。GATE はしきい値以下で RANGE の分
(バーの端から端まで 38 dB)、COMP は画面が描いているカーブがユニティからどれだけ下に居るか
(しきい値と同じ 54 dB)、DUCKER は Ducker Source に選んだストリップのレベルをしきい値と比べ、
RANGE までで止める。OUT メーターはその分だけ IN より下を読み、ブロックが後ろで足し直す分
(COMP のメイクアップ) だけ上へ戻る — メイクアップがリダクションより深ければ OUT は IN より
上を読む。何も押さえないブロック (DELAY・[No Effect] の INS FX) の IN と OUT は同じ。
バーと OUT のずれは、画面を描き直さずにメーターを動かす仕組みが毎回計算し直す。

設定のパネル (x250..418 / 高さ 36px / 間隔 8px) は画面下から積む。最下段はカーブのパネルの足元と
同じ高さで、DUCKER が 1 枚 (Threshold)、COMP が 2 枚 (Attack / Release)、GATE が 3 枚
(Attack / Hold / Decay)。値ボックスは 52x22 で右端から 7px 内側。

つまみ (G / T / R / A / D) は直径 32px (面 `--handle-face`、縁 3px `--handle-ring`)、左右の端は
パネルの内側へ半径ぶん寄せる。触れたつまみがフォーカスを持ち、その 1 つだけ縁が `--accent-focus` になって、
値の動く向きの両側に `--handle-arrow` の三角が付く (GATE の T・COMP の T・DUCKER の A と D は左右、GATE の R・COMP の
G と R・DUCKER の R は上下)。三角は 2 秒周期で徐々に消えて戻る。画面を開いた直後はどのつまみもフォーカスを持たない。
つまみはその値のコントロールで、ドラッグ・ホイール・矢印キーで回る (ユーザーガイド「GATE screen」「COMP screen」の b、
「DUCKER screen」の a)。GATE の T はしきい値・R は RANGE、COMP の T はしきい値・G は Gain・R は Ratio、DUCKER の R は
RANGE・A は Attack・D は Decay を回す。ドラッグは三角の向きに沿い、COMP の R は下へ引くほどレシオが上がる (高いレシオほど
カーブの右端が下がる。URX44V、2026-09-22 操作者確認)。COMP の 1-knob が入っているあいだはどのつまみも回らず、G・T・R は文字の無い半分の大きさの輪 (細い灰色の線・中は淡いマゼンタ) になり、
曲線もマゼンタになる (EQ の 1-knob と同じ描き方。URX44V、2026-09-23 操作者確認)。Auto Makeup が入っているあいだは G が回らない。
押して持ったつまみにはこの縁と三角だけが付き、ブラウザのフォーカスリングは出ない (キーボードで移ったときだけ出る)。
三角はどのつまみよりも上に描くので、近くのつまみに隠れない。つまみは、値がグラフの上や下へ出る位置を指しても丸全体を
グラフの中に置き、丸の端を枠に接する (GATE の工場出荷値 -50 / -56 で R の縁が y221..222、枠が y223)。枠に接したつまみの
枠の外側の三角は見えない。

- GATE: 伝達曲線。スレッショルドを超えた分はそのまま、下回る分は RANGE だけ下げるので、
  平行な 2 本の線がスレッショルドで段になる。T がスレッショルド、R がその下の RANGE。
- COMP: 伝達曲線。`out = in + Gain` をスレッショルドで折り、レシオで寝かせる。折れ目は Knee の幅で丸める
  (Soft 52 dB・Medium 16 dB・Hard 0 dB)。G と R はパネルの左端・右端、T は丸めた曲線の上のスレッショルドの位置。
  Ratio は「SSMCS の 4 画面」に挙げた段をそのまま通り、読みだけが違って 100 以上も小数第 1 位まで書く
  (`100.0:1`・`500.0:1`。URX44V、2026-09-23 操作者確認)。
  最上段の INF:1 では曲線がしきい値から上で水平になる (同日の操作者確認)。
- DUCKER: 包絡線。キーが鳴っているあいだ RANGE まで下げ、止むと戻る台形。R が RANGE の高さ、
  A と D が下りと上りの角。

伝達曲線のパネルは両軸とも -80..+20 dB で、0 dB に縦横 1 本ずつ罫線が入る。罫線は曲線の下の塗りに
重なる区間を `--graph-grid-lit` で描く (p103-1 の x180)。罫線は画素の 1 列・1 行に揃える (p103-1 と p099-1 の x180・y86)。包絡線のパネルは
縦が -100..+20 dB で、RANGE の高さに横罫、A と D に縦罫が入る。

リダクションバーは上から下へ伸びる。COMP はスレッショルドの可動範囲 (54 dB) を全長とする。GATE は入力が
スレッショルド以下のあいだ RANGE の分だけ伸び、38 dB を全長とする (p103-1 は RANGE -20 dB で y118..174)。
GATE の OUT メーターは IN より同じ分だけ低く振れる。

COMP と EQ の右上には [1 1-knob] ボタン (x386..477 / y50..87、面 `--surface-btn`、丸マーク
18px で中の 1 はボタンの面の色で抜く、消灯の帯は `--oneknob-band`、名前は 14.5px・太さ 600 で 3px 左・2px 下)。COMP はその左に Auto Makeup のドロップダウン (x306..375 / y49..88)、下に Knee
(x294..417 / y96..135)。DUCKER は上段に Ducker Source のキャプションとドロップダウン
(x352..418 / y52..91)。

1-knob がオンのあいだ、その行は右端まで届くパネル `--oneknob-panel` (y47..90) に載る: 枠付きのレベル (55x30、
x315..369 / y54..83)、線 `--oneknob-link` (x373..382 / y68..69)、点灯したボタン `--oneknob-lit` と帯
`--oneknob-lit-band` (p104-2、p106-2)。COMP はパネルが x311 から始まり、Auto Makeup はそれに場所を譲る。Knee は
見た目のまま開かない。EQ はパネルが x179 から始まり、バンドの形の
代わりにカーブの種類 (Intensity / Vocal / Loudness、124x38 の丸い箱 `--oneknob-type`、右端 x306) を先頭に置く。
グリップは名前の無い約半分の大きさの輪になり、線は淡色の `--accent-cue`、中はグラフの地 `--graph-bg` で、触れてもバンドを
選ばない。カーブの線は `--eq-line` の緑ではなく `--accent-focus` のマゼンタになる。

1-knob の Level は EQ の 4 バンドの値を書き換える (ユーザーガイド「How 1-knob EQ works」)。1-knob を入れたとき、または
入のあいだに Intensity を選んだときの 4 バンドのゲインを基準に取り、Intensity の Level は各ゲインを基準 × Level / 50 にする
(50 で設定どおり、0 で平ら、100 で 2 倍)。Loudness を選ぶと 4 バンドを LOW が Bell・Q 0.56・90 Hz、L-MID が Q 1.00・400 Hz、
H-MID が Q 1.00・2 kHz、HIGH が H.Shelf・Q 1.00・6 kHz にして 4 バンドとも入・ゲインを 0 にし、その Level は 1% あたり LOW に +0.20 dB、
L-MID に −0.20 dB、H-MID に +0.02 dB、HIGH に +0.10 dB を与える。Vocal を選ぶと LOW を HPF・80 Hz、L-MID を 335 Hz、H-MID を
3 kHz、HIGH を Bell・8 kHz (Q はどれも 0.71) にしてゲインを 0 にし、LOW を切って残りの 3 バンドを入にする。どちらも選ぶ前のバンドの入切を引き継がない。その Level は 1% ごとの表で、LOW を入にして
コーナーを 80 Hz から 140 Hz まで上げ、L-MID を −6.0 dB まで下げ、H-MID を +2.0 dB まで上げ、HIGH を 77% の +2.0 dB まで上げて
93% で 0 に戻す。ゲインはどれも 0.1 dB に揃い (ちょうど半分は + 側へ)、±18.0 dB で止まる。1-knob を切ってもバンドは Level が
置いた値のまま。

ダイナミクス画面の IN / OUT メーターの本数は図が割れている。同じモノラルチャンネルを
p099-1・p106-1 は 2 本、p103-1・p113-1 は 1 本で描く。実機はモノラルで 1 本なので、
ストリップのチャンネル数に従う。FX チャンネルだけは左右で本数が違い、入りが 1 本・戻りが 2 本。
1 つのバスで受けてステレオで返すため。

## エフェクトの画面

INS FX と FX チャンネルのエフェクトは、エフェクト名のボタンで種類を選び、その画面でそのまま設定する。
INS FX 画面はエフェクトの設定画面そのもので、開いた直後から値が回る (URX44V、2026-09-23 操作者確認)。
ガイド「HOME 画面 (Overview) からインサートを操作する」の手順 3 と 4 が「エフェクトエリアに触れると
パラメーター設定画面が開く」と書くが、実機は触れる一段を挟まない。

FX チャンネルは INS FX 画面を挟まない。チャンネルビューのパネルがチャンネルの名前 (FX1 / FX2)・空行・
走っているエフェクトの名前の 3 行で、名前はスイッチではなくラベル。チャンネルの名前はパネルの幅の中央に白で
書く (URX44V、2026-09-22 操作者確認)。触れるとパラメーター設定画面が開く。
その画面のツールバーは、チャンネルの送りと戻るボタンのあいだにエフェクト名のボタン (複製マーク付き) と
チャンネルの名前を置く。エフェクトの選択画面の題は `EFFECT TYPE`。HOME のストリップにはエフェクトの
名前を出さない。

サンプリング周波数が FX チャンネルのエフェクトをすべて上限より上へ追い出すと (FX 2 の 176.4 / 192 kHz)、
そのストリップは**名前の行の 1 行目だけ**を残して使えなくなる。色のマークも名前の 2 行目も、その下の
インジケーター・メーター・[ON] / [CUE]・ロータリー・レベルの値もどれも描かない。ストリップの面は
そのままで、下端のレールはチャンネルの色の代わりに濃いグレーで描く。ストリップは選べるが、触っても
チャンネルビューは開かない。

図版がガイドに無いので、**並べ方はこのプロジェクトが決めたもの**。ガイドが決めているのは、コントロールが
画面の中央に並ぶこと (p113-1 の中央は [No Effect] のときの空) と、入出力メーターが右端に立つことだけ。

パラメーター設定画面は 1 ページに 8 つ、横 4 つ・縦 2 段でコントロールを並べる。セルは幅が DELAY 画面と
同じ 86、高さは DELAY の 84 より 2px 低い 82 で (2026-09-24 の操作者指定)、x12..411 / y53..224 (2 段目は y143 から、行の間隔 8px)。列はオシレーターの箱と同じ
決まりで、つまみの読み出し帯の区画の上に重ねる (x12・116・222・326。区画の中心との差は 0.5px 以内)。
セルはキャプション (15px) の下にコントロールを置き、値が連続して変わるものにはその下に
直径 38 のつまみを添える。
コントロールは値ボックス・プルダウン・入切ボタンの 3 種で、値ボックスは DELAY 画面のセルと同じ 60x22 の箱
(角も同じ)、プルダウンと入切ボタンは 78x22 の箱に収める。入切ボタンは OSCILLATOR の [ON] と同じく、パネルを地にした角と 4px の帯で描く。各ページは 4 つずつの組を下の段から寄せて置く: 4 つ以下の
ページは下の段に並び (Rev-X Hall の 2 ページ目の HPF / LPF)、5〜8 つのページは最初の 4 つを上の段、残りを
下の段に置く。つまみの読み出し帯は 1 段ずつ、下の段を先に、上の段を後に読み、各値をそのパネルの下の区画に置く。
回せる値の無い区画は空け、回せる値の無い段はつまみのページを持たない。区画の並びをパネルの位置と一致させるのは
ほかの画面と同じ決まり (同日の操作者指定)。ページを開いたときと送ったときに、読み出し帯が最初に読む値に
フォーカスの枠を付ける。Rev-X Hall で実機と一致した (URX44V、2026-09-22 操作者確認)。M.B.Comp はこのパネルの
並びを使わず、チャンネルの COMP と同じ枠で描く (下の「M.B.Comp の 4 ページ」)。Clean の並びは実機と同じで (同日の操作者確認)、1 ページ目の上段が
Volume / Distortion / Blend / Output、下段が Treble / Middle / Bass / Presence、2 ページ目の上段が Cho・Off・Vib / Gate /
SP Type、下段が Speed / Depth / Gate Level / Mic Position。Cho・Off・Vib は上段の左 2 欄 (2 本の列とそのあいだ、190px) に、
キャプション無しで 3 つのボタンを横に並べる (3 つめは `Vib`、同日の操作者確認)。幅は 59・60・59 (2026-09-24 の操作者指定)。選んだボタンは `--accent-selected` のシアン。
Gate はキャプションを持たず、Cho・Off・Vib と同じ暗い面のボタン自体に `Gate` と書き、並びのボタンではないので 4 隅とも丸め、幅はパネルと同じ 86px にする (同日の操作者指定)。Cho・Off・Vib・Gate・SP Type・Mic Position の 4 つはパネルの面を
持たずにガラスに立ち、ボタンとプルダウンの高さはツールバーのエフェクト名 (40px) の 9 割の 36px。SP Type と Mic Position は
キャプションを `--text-muted` の濃い灰色にしてプルダウンから 4px 離し、キャプションとプルダウンを欄の下端に寄せ、プルダウンを
その下の読み出しバーの区画の幅にする (4 列目は x317..419)。上段の SP Type はプルダウンの下端が下段の Mic Position のキャプションの
8px 上に来るまで下げ、上段の Cho・Off・Vib と
Gate は下端を SP Type のプルダウンの上端にそろえる (同日の操作者指定)。Gate も Cho・Off・Vib と同じく、入のときシアン (同日の操作者確認)。キャプションとプルダウンの 4px と
下端の余白 (4px) は、図が無いのでこのシミュレーターが決めたもの。
Crunch・Lead・Drive の並びも実機と同じで (同日の操作者確認)、1 ページ目の上段が Type (Drive は Amp Type) / Gain / Master
(Crunch は空き) / Output、下段が Clean と同じ Treble / Middle / Bass / Presence。2 ページ目は Clean の Cho・Off・Vib・Speed・Depth の
場所を空け、Gate・Gate Level・SP Type・Mic Position を Clean と同じ場所に同じ描き方で置く。Type と Amp Type はプルダウンではなく
値の箱とつまみで、つまみを回すと名前を 1 つずつ切り替える (同日の操作者確認)。
Mono Delay の並びも実機と同じで (同日の操作者確認)、1 ページ目の上段が HPF / LPF / 空き / 空き、下段が Delay / FB.Gain /
Hi.Ratio / 空き、2 ページ目の上段が Sync / 空き / 空き / BPM、下段が空き 3 つと Note。読み出し帯は 1 ページ目が
Delay / FB.Gain / Hi.Ratio / 空き、送った先が HPF / LPF / 空き / 空き、2 ページ目が空き 3 つと BPM。Sync は Gate と同じく
キャプションを持たず、ボタン自体に `Sync` と書く。Note はパネルの面を持たないプルダウンで、幅はパネルと同じ 86px、
キャプションとプルダウンを SP Type・Mic Position と同じ 4px の間隔・4px の下端の余白で欄の下端に寄せる (どれも同日の操作者指定)。
Sync の上下の位置は Gate と同じで、Note のキャプションは SP Type と同じ濃い灰色 (同日の操作者確認)。Ping Pong も
Mono Delay と同じ並び (同日の操作者確認)。Rev.R3 の並びも実機と同じで (URX44V、2026-09-23 操作者確認。Hall で読んだもので、3 面は同じ組み立て)、
1 ページ目の上段が Density / FB.Gain / E/R Delay / E/R Bal.、下段が Rev.Time / Ini.Delay / Hi.Ratio / Diffusion、2 ページ目の下段が HPF / LPF。
選択肢が 6 つ以上のプルダウンは箱の下に垂らさずシートで開く。ただし Note はシートを開かず、欄の左に 3 行 5 列の一覧を
開く (同日の操作者指定、位置は同日の操作者確認)。一覧は背景に何も無い場所になるべく重ね、Note の欄 (x326..411) と読み出し帯 (y233) から 2px 離して
x60..323 / y107..230 に置く。一覧の幅 264px は、欄の左の空き (Sync の右の x98..325) より広いので、左端が Sync の下端
(x60..97 / y107..121) に重なる。Cho・Off・Vib のほかは、どのコントロールも 1 つぶんの場所に
収め、名前がセルに収まらない選択肢 (Pitch Fix の `Harmonic Minor` 等) は他の長すぎる名前と同じく
末尾を `…` にする (全文はシートで読む)。右端にはブロックの入出力メーター (x430..473) が、
ダイナミクス画面と同じ位置・同じ大きさで立つ。

値ボックスと読み取りの表示は、実機と同じく単位 (Hz・kHz・s・ms・dB・%) を付けず数字だけを書き、画面の下の
つまみの読み出し帯は単位を付ける (どちらも URX44V、2026-09-22 操作者確認)。FB.Gain と Pitch Fix の
Coarse・Fine・Formant は、値の箱でも読み出し帯でも 0 より大きい値に `+` を付けず、負の値にだけ `-` を付ける (同日の操作者確認)。

8 つに収まらないエフェクトはページに分け、SSMCS と同じ丸いページ送りボタン (36px) を SSMCS と
同じ位置 (x4 と x386 / y117) に置く。ボタンは左右端のパネルの角に重なる。送る先が無い側には
ボタンを描かない。ページは、エフェクトを選び直したときと
チャンネルビューのパネル (INS FX / FX チャンネル) から開いたときに先頭へ戻る。

### Pitch Fix の 3 ページ

Pitch Fix も 3 ページに分かれる (URX44V、2026-09-23 操作者確認)。[Correction] はどのページでも右上
(x390..476 / y50..78、COMP の [1 1-knob] と同じ位置) に立つ。ページの名前を持つページは、その名前を
パネル 2 つ分の幅の帯 (x12..202 / y106..130、読み出し帯と同じ面と字の色) に書いて、名前が指すパネルの上に置く。

1 ページ目は `Pitch` の帯の下に Coarse / Fine / Formant を下段の左 3 つ。Coarse と Fine は半音と
セントだが、実機は箱にも読み出し帯にも単位を書かない。読み出し帯だけ Coarse を `Coarce` と綴る。

2 ページ目はパネルを使わず、左に MIDI Control / Key / Scale のキャプションとプルダウン (幅 100・高さ 36) を
縦に 3 つ並べ (y5・y67・y128)、その右に 1 オクターブの鍵盤 (x141..420 / y90..219、白鍵 7 つと黒鍵 5 つ)。
12 音すべてに音名を書いた丸 (26px) を置き、補正が取る音は [1 1-knob] の点灯色、取らない音は隣のプルダウンと
同じ面の色で描く。丸を押すとその音が裏返り、Scale が `Custom` になる。Scale に名前のある音階を選ぶと 12 音を
その音階で埋め直し、Key を替えたときも同じように埋め直す。`Custom` のあいだは、`Custom` を選び直しても
Key を替えても 12 音は動かず、名前のある音階へ自動で戻ることもない (URX44V、2026-09-23 操作者確認)。
読み出し帯は空。

3 ページ目は `Note Limit Low/High` の帯の下に Limit Low / Limit High / Speed / Tolerance を下段へ、
Mix を上段の左から 3 つ目に置く。読み出し帯は下段の 4 つが 1 段目、Mix が 2 段目の 3 区画目。

### M.B.Comp の 4 ページ

M.B.Comp はパネルを並べず、コンパンダーと同じくチャンネルの COMP の枠で描く (URX44V、2026-09-23 操作者確認)。
ページは 4 つで、送るのはほかのエフェクトと同じ丸い矢印。

1 ページ目は帯域そのもの。グラフは横が周波数 (20 Hz..20 kHz の対数)、縦が帯域のゲイン。帯域は隣の
クロスオーバーまでをゲインの高さまで塗り、Low は伝達曲線の線の色、Mid と High はそれぞれの色で塗る。
つまみは 5 つで、L・M・H が帯域の真ん中に立ってそのゲインを上下に動かし、LM・MH が帯域の境目に立って
クロスオーバーを左右に動かす。右には Out Gain のパネル (キャプション・値の箱・つまみの絵)。読み出し帯は
Low Gain / Mid Gain / High Gain / Out Gain。

2〜4 ページ目は Low・Mid・High の 1 帯域ずつ。グラフはその帯域の伝達曲線で、線と塗りは帯域の色。
つまみは T (しきい値) と R (レシオ) の 2 つ。右は上から帯域の名前、[Bypass] のボタン、Attack と Release の行で、
Release はエフェクト全体のもの。読み出し帯は Threshold / Ratio / Attack / Release。

寸法は実機の画面から起こした (URX44V、2026-09-23)。曲線のプロットはほかのダイナミクス画面より左へ寄って
x4 から始まり、幅は同じ 200px。1 ページ目のグラフだけ 265px と広い。リダクションメーターは 6px のバー 3 本を
6px あけて並べ (`GR` と `L M H` の字を上に置く)、足元をプロットの足元にそろえ、プロットと右隣の部品の
あいだの中央に置く (帯域のページは x211、1 ページ目は x280.5)。開いている帯域のバーには白い枠が付く
(1px、バーから 1px 離し、バーの丸い端に沿わせる)。Out Gain のパネルは右端から 68px。

読み出し帯は 1 ページ目が Low Gain / Mid Gain / High Gain / Out Gain で、2 段目が L-M Xover / M-H Xover
(Release はここに無い)。帯域のページは Threshold / Ratio / Attack / Release で、2 段目の左端にその帯域の Gain。
どのページも、値の箱で出している値 (1 ページ目は Out Gain、帯域のページは Attack) にフォーカスの枠が付く。

1-knob を入れると、帯域の値と Release・L-M Xover・M-H Xover は実機が自分で持つので、箱は読みだけを残して
操作を受けず、[Bypass] はページから消え、つまみの読み出し帯は 1-knob Level だけになる。グラフのつまみは
EQ の 1-knob と同じく文字の無い半分の大きさの輪 (細い灰色の線) になり、中と曲線の塗りは淡いマゼンタ、
曲線の線はマゼンタに変わる。チャンネルの COMP 画面の G・T・R も 1-knob 中は同じ描き方になる。つまみは
輪の線まで含めてプロットの枠の内側に収める。

Clean の Speed と Depth は、Cho / Off / Vib のどれを選んでも見た目も操作も変わらない (Effect Reference Guide「CLEAN Only」の
「Not available when "Cho" is On.」は音への効き。URX44V、2026-09-22 操作者確認)。Mono Delay と Ping Pong は
Sync が入っているあいだ、Delay (Ping Pong は Delay Time) を Note の音価を BPM で数えた長さ (4 分音符は 60000 / BPM ms) にする。
決め直すのは Sync を入れたときと Note・BPM を動かしたときで、そのディレイの届く範囲 (Mono Delay 0.1..2700.0 ms、Ping Pong
1.0..1350.0 ms) で止まる (Effect Reference Guide「Delay Section」)。Delay の欄は Sync のあいだも普段の面で回せ、回しても
Sync は入のままで、次に Note か BPM を動かすと音価の長さに戻る。Sync を切っても Delay の値はそのまま。Sync の入切は Note の
表示にも選べる項目にも影響せず、BPM 60 の Note の一覧に選べない音価は無い (URX44V、2026-09-22 操作者確認)。Sync が切のあいだ
Note を動かしても Delay は決め直さない (Note は「when tempo sync is enabled」の音価)。
Note の欄と一覧は音価を音符の絵で描く。一覧は 15 項目を左上から行ごとに 3 行 5 列に並べ、左上の `---` だけが文字、残る 14 は
Effect Reference Guide の Mono Delay の表の注と同じ 7 行の点の字形 (URX44V、2026-09-22 操作者確認)。字形の 1 点を画面の
2 画素で描く大きさと、一覧の 1 項目を Ducker の Source の一覧と同じ 48x36 にする大きさは、図が無いのでこのシミュレーターが
決めたもの (`src/ui/icons.ts` の `NOTE_PIXELS`)。

Compander-H / Compander-S だけはパネルで並べず、チャンネルの COMP と同じ枠で描く。左にカーブ、
その右にリダクションメーター、続いて Attack・Release・Ratio の 3 つの設定、右端にブロックの入出力
メーター。この並びと下の読み出し帯の 2 ページは実機と見比べて一致した (URX44V、2026-09-23 操作者確認)。設定の値ボックスは幅が狭いので、チャンネルの COMP と同じくミリ秒を `m` と略す (読み出し帯は
`ms` のまま)。読み出し帯には 6 つ全部が 4 つずつ 2 ページで載る (1 ページ目 Threshold・Ratio・Width・Gain、
2 ページ目 Attack・Release)。

カーブのグリップは 3 つ。(T) は Threshold の角に立ち、左右のドラッグでしきい値を動かす。(W) は帯の
足元 (Threshold − Width) に立ち、**左へ引くと帯が広がる** (グリップは値と逆向きに動く位置にあるため。URX44V、2026-09-22 操作者確認)。
(G) はプロットの右上、円の線の幅だけ右の枠をあけた位置に立ち、上下で Gain を動かす。どれも触れると
ピンクの枠が付き、ドラッグ・ホイール・矢印キーで回せる。

円が重なって読めなくなるのを防ぐため、(W) は (T) の円半分手前で止まり (値は止まらない)、プロットの
左端からも円半径分より内側に留まる。(G) の位置は動かない — しきい値が上限まで来ても (T) との間が
円半分を下回らないため。描く順は (W)・(T)・(G) で、重なったときに上へ出るのは (G)。

コンパンダーの設定は 1 画面に収まる。ほかのエフェクトと同じく INS FX 画面がその設定画面そのもので、
グリップも値ボックスも読み出し帯もその画面で効く。

カーブは出力を**グリッドの交点 (入力 0.0dB / 出力 0.0dB)** で抑える。Gain の上限が 0.0dB で、そのとき
交点から右端までは横の罫線に沿った水平線。Gain を下げると水平線ごとカーブ全体が同じだけ下がる。
交点から (T) までは Ratio が傾きを寝かせ、(T) と (W) のあいだ (帯の幅 = Width) は 1.0:1。(W) より下は
さらに急に落ち、その傾きはエフェクトごとに決まっている: **Compander-H が 5:1、Compander-S が 1.5:1**
(実測値。Width や Ratio では変わらない)。

### エフェクトの選択

シートの帯はチャンネルによらず `EFFECT TYPE`。インサートのシートは [No Effect] が 1 行目に単独で立ち、
エフェクトは 2 行目の左から 1 行 4 つ。FX チャンネルは [No Effect] を持たず、1 行 3 つで並ぶので、
1 行目がリバーブ 3 種、2 行目が Mono Delay と Ping Pong になる。

チャンネルが取れるエフェクトはガイドの「エフェクトリスト」が決める。取れないものもシートには
並べ、押しても何もしない面で描く。取れなくなる理由は 3 つ:

| 理由 | 対象 |
| --- | --- |
| サンプリング周波数が上限を超えている | Pitch Fix は 48kHz まで、ギターアンプとコンパンダーと M.B.Comp は 96kHz まで、FX2 のエフェクトは 96kHz まで |
| チャンネルが 1 本のステレオ信号を運んでいる | ギターアンプ 4 種と Pitch Fix |
| 同じ枠を他のチャンネルが使っている | ギターアンプ 4 種で 1 枠、Pitch Fix で 1 枠、コンパンダー 2 種で 1 枠、出力側は M.B.Comp とコンパンダー 2 種で 1 枠 |

入力チャンネルのコンパンダーとバスの M.B.Comp は別の枠なので同時に使え、バスの 1 つが M.B.Comp を使っているあいだ
ほかのバスは何も選べない (URX44V、2026-09-22 操作者確認)。

エフェクトを選ぶとブロックが入になり、そのエフェクトの値が実機の初期値に戻る。同じエフェクトを
選び直しても戻る。[No Effect] のあいだは INS FX のスイッチを押しても何も起きない。

サンプリング周波数を上限より上へ上げると、そのインサートはチャンネルから外れて [No Effect] になり、
周波数を戻しても戻らない。FX チャンネルは [No Effect] を持たないので外れる先が無く、走っているエフェクトは
そのまま残り、そのあいだは選択シートのどれも押せない。Signal Type を切り替えると、どちら向きでも組の
両チャンネルからインサートが外れる。ステレオリンク中の組は 1 つのインサートを共有し、若い番号の
チャンネルが持つ。

## DELAY 画面

Frame rate は 24 / 25 / 29.97D / 29.97 / 30D / 30 / 60 / 120 の 8 つで、2 列 4 行のシートに出す。
`D` はドロップフレームで、フレーム数への換算は名前の中の数字が決める。時間そのものは変わらない。

p115-1 実測。上段に Frame rate のキャプション (x15..76)、ドロップダウン (x100..166 / y48..87、

## EQ 画面

p106-1 実測。左上に選択中のバンドの箱 (x2..56 / y49..86、面 `--accent-band`、名前は 14px の太字を 1 行で中央に置き、HIGH が
x12..45 / y62..71。中の 2 バンドは L-MID と H-MID)、中央にフィルター形状の箱 (x283..376 / y50..87、両端が半径 19px の半円、面 `--shape-box`、
1px の縁 `--shape-box-edge`、影の帯は無く、▼ は 9x8 で x356..364 / y66..73)、右に [1 1-knob]。
形状の箱は名前ではなく 30x20 の線画で形状を示す (Bell は横線の中ほどにレンズ形、p106-1 の
x310..339 / y60..79)。LOW は Bell・L.Shelf・HPF、HIGH は Bell・H.Shelf・LPF から選び、LOW MID と HIGH MID は Bell のまま変えられない
(箱は Bell と ▼ を出したまま不透明度 0.5 で減光し、押しても開かない)。L.Shelf は左の上下 2 本が幅 30 のうち x11 から寄って x18 で 1 本になり、HPF は左下から x13 まで
立ち上がって水平に伸びる。H.Shelf と LPF はその左右反転。箱を押すと、形状の箱と同じ 94x38 の線画だけのボタンが縦に並ぶ一覧が

その下が 416x138 のグラフ (x2..417 / y93..230) で、横軸は 20 Hz..20 kHz の対数、縦軸は
±20 dB。罫線は 100 Hz / 1 kHz / 10 kHz と ±10 dB / 0 dB。4 バンドのつまみはそれぞれの周波数と
ゲインの位置に立ち、押すとそのバンドがノブに載る。つまみを引くと横で周波数、縦でゲインが動き、そのバンドがノブに載る

## SSMCS の 4 画面

COMP / EQ のタイプを SSMCS にした MONO IN のチャンネルが持つ。チャンネルビューは COMP と EQ の 2 つの area を
1 つの SSMCS area に置き換える (`ch.<id>.compEqOrder` が `SSMCS`)。ステレオ・FX・バスのチャンネルはタイプを持たないので
置き換えも起きない。

2 つのタイプは実機の中で別のバンクで、切替をまたいで保たれない。タイプを取ると**取った側のバンクが
工場出荷の値で読み込み直される** — SSMCS に入ると COMP と EQ が入になり SSMCS の全値が戻り、
COMP→EQ に入るとコンプ・4 バンド EQ・EQ の 1-knob が戻る。**出た側のバンクはそのまま**で、
次にそこへ入ったときに読み込み直される。GATE はタイプに依らないので動かない。
同じタイプを選び直したときは何も起きない。4 画面は画面の左右に重なる丸い矢印で行き来し、押すとスタックを積まずに今の画面と入れ替わる
(戻る矢印 1 回でチャンネルビューへ戻る)。矢印は 36x36 の円 (面 `--page-arrow` = 白の不透明度 0.48、x2 と x384、y67)、
中の山形は 8x12 で `--lcd-bg`。最初の画面に戻る矢印は無く、最後の画面に進む矢印は無い。

メイン (p108-1 実測)。上段に 2 つのブロック (面 `--surface`、角 `--radius-lg`): COMP が 165x90 で x0/y0、EQ が 237x90 で
x173/y1。ブロックのスイッチはチャンネルビューのブロックと同じ 60x20 の小さい箱で、COMP が x4/y7、EQ が x7/y7。
中の縮図は面 `--graph-bg` で、COMP が 81x73 (x69/y7)、EQ が 159x75 (x73/y7)。縮図もそれぞれの寸法の座標に描き、
COMP は縦 0.8・横 0.2 の罫線、EQ は 100 Hz / 1 kHz / 10 kHz と +10 / 0 / -10 dB の罫線を持つ。COMP ブロックの右端に 4x56 の
ゲインリダクションメーター (x155/y14)。下段は 2 つのパネル (面 `--surface-sunk`、角 `--radius-lg`): Comp Drive が 86x84 で
x10/y94、Morphing が 300x84 で x114/y94。名前・値・つまみはパネル左の 86px の列に揃え、名前は 13px で中央から 2px 左 (y2)、
値の箱は 52x22 (x17/y19)、つまみは x20/y46。Morphing のパネルには Sweet Spot Data のボタンが並ぶ (202x37、x198/y117、
面 `--surface-on-sunk`、複製マーク 11x11 を右 4px・上 5px)。押すと 34 件の名前を 2 列で並べたシートが開く。

COMP (p110-1 実測)。左上に [Comp] の題の箱 (93x38、x0/y-1。面 35 行の下に 3 行の帯)。カーブは 200x132 の枠
(x19/y40、内側 198x130) で、-80..+20 dB を 198x130 の座標に描く (GATE / COMP の 198x171 とは高さが違うので、

## メーターの色帯

メーターのバーは下半分が緑、上半分が黄で、バーそのものに赤は無い。赤く灯るのはバーの上の
クリップ点で、レベルがそのメーターの上端に届いたときに点く。境目はバーの中央に置き
(高さが奇数行のバーでは真ん中の 1 行が黄になる)、メーターの長さや min/max が違っても
動かない。点灯するのはレベルの位置から下だけで、境目はバー自身の中央から動かないので、
レベルが動いても帯の位置は変わらず、消灯部には色帯の色が乗らない。レベルの位置は 1 行単位に丸める。

バーとクリップ点の端は、実機が角を描く中間色の画素で描く。幅 4px の部品は端の行の角 2 画素と
次の行の両脇、幅 6px の部品は端の行の角 2 画素 (その外側は地の色) と次の 2 行の両脇に色が乗る。
色はメーターの地ごとに `design-tokens.md` の `--meter-*-outer` / `--meter-*-inner` にある。上端まで
点いたバーの角は図のある p079-2 (幅 4px) と p106-1 (幅 6px) の値をその幅のメーターに使い、点いた
クリップ点の角は p106-1 の値を幅に関わらず使う。COMP のゲインリダクションバーも同じ描き方で、
上端は `--gain-reduction-outer` / `--gain-reduction-inner`。
点灯部の上端がバーの上端より下にあるときは、点灯が始まる行とその下の行の両脇を同じ形で描き (幅 6px の
部品では端の行の角の外側がバーの消灯部の色になる)、各行の色はその行が黄と緑のどちらに点いているかで
決まる。色は `--meter-*level-*` にある。

メーターの色帯の位置は図が割れている。緑の上に黄が灯り、その境目がバーの中央に来る図は
p036-1・p037-1・p045-1・p047-1・p048-5・p048-6・p067-1・p081-1・p090-1・p094-1・p098-1・
p098-2・p099-1・p103-1・p104-1・p106-1・p108-1・p110-1・p111-1・p112-1・p115-1。中央より上まで
緑が伸びる図は p048-1・p049-1・p051-2・p051-3・p094-2・p094-5・p113-1・p114-1 で、このうち
黄も灯っている p051-3 の STEREO/CUE メーター (バー y149..219) はバーの 69% で黄に変わる。
p106-1 の OUT メーターは黄がバーの上端まで灯り、その上のクリップ点が赤い。実装は中央の側に従う
(「メーターの色帯」の節)。

## ボタンの影

ボタンは下端 3px が影の帯で、名前はその帯を除いた面の中心に置く。メニュー項目・言語や
Operation Mode の選択肢・ドロップダウン・汎用ボタンのいずれも同じ (p041-1 / p078-1 実測)。

帯の色は面で決まる。面 (74,81,90) の帯は `--btn-bevel` の (49,57,58)。使えないボタンは `--btn-bevel-disabled`、
沈んだ面のソースボタンは `--btn-bevel-sunk`、[Follow USB] と USER DEFINED KNOBS のノブのカードは `--btn-bevel-plain`。
消灯したブロックのボタンの面 (214,206,214) は、面を 27% 暗くした (156,150,156) の帯を持つ。
CH SETTING の Color の選択肢と、チャンネルバンク一覧の項目 (表示中のバンクを含む) は、面を `--px-band-cast` (31%)
だけ落とした帯を持つ。

帯を持つコントロール (ボタン、チャンネルビューのブロックや UDK のカードのようなパネル) は、ポインタで押さえているあいだと、
フォーカスのあるコントロールで Enter / Space を押しているあいだ沈む: 帯が消え、帯を除いた面が帯の深さ (3px、[ON] /
[CUE] / [PRE] は 4px) だけ 30ms で下へずれて帯の位置を覆い、面の上には下地が見える。切り取りはコントロールの端で
行い、画素で描く角は沈んだ面の下端にも上端と同じ角を描き、ブラウザの角丸で描く部品は切り取る形も面と同じ 4 隅の
半径で丸める。キーで押しているあいだも、フォーカス枠はコントロールの元の位置に残る。キーを押したまま画面が描き直されたときは、
フォーカスが戻ったコントロールが代わりに沈む。キーを受けたコントロールが画面に残ったままフォーカスが別の場所へ移ると
(キーで開いたダイアログが [OK] にフォーカスを移すときなど)、そのコントロールは戻り、移った先も沈まない。どの
コントロールが帯を持つかはシェルが押した時点の計算済みの `box-shadow` から読むので (`src/ui/press.ts`)、帯を足した
コントロールは何もしなくても沈む。使えないコントロールは沈まない。`prefers-reduced-motion` では動きのアニメーションを
付けない。

microSD の [USB Storage Mode] は他のボタンと同じ面で、モードが入っているあいだだけ
`--accent-selected` に変わる (p078-1 はモードが入っている状態)。モードが入っているあいだも、ツールバーの HOME は普段の見た目で
HOME へ移り、他の画面も開く (URX44V、2026-09-22 操作者確認。ガイドとの違いは [known-issues.md](known-issues.md)「実機にも無いもの」)。

## RECORDER

Record タブのスロットのメーターは、録音しているかどうかによらず、そのスロットのソースのレベルを出す
(ユーザーガイド「RECORDER menu」の Record の c)。ペアのソースはチャンネルを 1 本ずつ、バスはステレオで出す。
p079-2 は録音していない状態で、STEREO を選んだスロットのメーターが点き、CH のペアを選んだスロットは点かない。
ツールバーの [Track Count] は面 x7..130 / y2..38 に立ち、名前を左寄りに、▼ を右端に置く (p079-2)。
一覧は 8 つを 2 列 4 行で出す (p079-3)。レコーダーが運べる本数はサンプリング周波数で決まり、
44.1 / 48 kHz が 16、88.2 / 96 kHz が 8、176.4 / 192 kHz が 2。運べない本数も一覧には並べ、
押しても何もしない面で描く。**周波数を上げると本数はその上限まで落ち、周波数を下げても戻らない。**
落ちるのは周波数が動いた瞬間で、動かす経路は 3 つ — SAMPLING FREQUENCY の画面、設定ファイルの
読み込み、保存された状態からの起動。本数を上げ直す手段はこの [Track Count] だけ。
スロットの Source ボタンの複製マークは 1.5px の線で `--rec-copy-mark`、ボタンの右上から 1px 内側に立つ (p079-2 の x378..387 / y185..194)。
録音は 4 つの状態を順に移る。画面を開いたときは止まっていて、中央のトランスポートのボタンは緑の三角で、押しても何もしない。
[●] を押すと録音待機になり、● が 2 秒周期で徐々に消えて戻る (EQ の持ったバンドの三角の半分の速さ)。待機中に中央の三角を
押すと録音が始まり、● は点灯のまま止まる。録音中は進捗バーの上に、サンプリング周波数 (x15..59) と経過時間 (x187..233) を
y235..244 に出し、中央のボタンは緑の三角の代わりに一時停止の白い 2 本の棒を出す (p079-1 の x320..331 / y243..256)。
経過時間は録音しているあいだ 1 秒ごとに進み、画面を作り直さずにその場で書き換える。この棒を押すと録音を中断し、中断中は
経過時間が止まり、棒を ● と同じ `--transport-rec` の赤で出す。赤い棒を押すと録音に戻り、経過時間は続きから進む。[■] を押すと
録音をやめて、画面を開いたときの状態に戻る。待機中にもう一度 [●] を押しても [■] と同じく画面を開いたときの状態に戻り、
録音中と中断中の [●] は何もしない。

待機中・録音中・中断中は録音モードにある。このあいだ、[Track Count] と取り出しボタンは表示をそのままに使えないボタンの面
(`--surface-disabled`、字と記号は `--menu-text-disabled`) になって押しても何もせず、Record / Play / Edit のタブとスロットの
Source ボタンは見た目を変えずに押しても何もしない。録音モードは RECORDER の画面を離れても続き、HOME とチャンネルビューの
ツールバーの microSD アイコンの右下 (x364..377 / y22..35) と、microSD トップの [Recorder] の名前の左 (x62..75、名前との間 4px) に
直径 14px の `--transport-rec` の丸を出す。microSD トップでは [Recorder] 以外 ([Save/Load]・[Tools]・[USB Storage Mode]・
取り出しボタン) が使えないボタンの面になって押しても何もしない。

TOOLS のツールバーにもカード取り出しボタンを置く (p087-1)。Format タブの [Format microSD] は、題の入力と同じ
キーボードの画面を題 `Volume Label` で開き、入力欄にカードのボリュームラベルを入れておく。この画面は 11 文字までを
受け、空でも [OK] で進む (空のときのボリュームラベルは `Untitled`)。[OK] でダイアログの枠と印を `--dialog-caution` に
した警告を出し、警告の [OK] で `Formatting in progress...` のモーダルを 5 秒出した後、カードを空にし、打った名前を
ボリュームラベルにする。Test タブの [Test microSD] は、`Loading...` と同じ形のモーダルを `Testing in progress...` の
文言で 3 秒出した後、ボタンの右に `Result : A`、その下に Card specs・
BUS Interface・UHS Speed Class・Speed Class・2 Tracks Recording・Multi Tracks Recording を 25px ごとに並べ、
評価と録音の 2 行を `--test-pass` にする (p088-2)。表の値はガイドの図のまま。

[Play/Pause] は一覧で選んだファイルを再生し、再生中に押すと一時停止、もう一度押すとそのファイルの再生に戻る。
別のファイルは [■] で止めてから再生する (ユーザーガイド「RECORDER menu」の Play の NOTE)。再生するのはカードに入った
2 トラックのファイルで、フォルダや 4 トラック以上のファイルを選んでいるときは何もしない (同じ節の Record の NOTE)。

[Play/Pause] の面は再生中も止まっているときも (74,81,90) で、印が替わる。再生中は白い一時停止の 2 本
(p081-1 の x320..331 / y243..256)、止まっているときは緑の三角。三角は操作説明の図 (Record タブの再生ボタンと同じ画像) による。

経過時間とサンプリング周波数は、再生中と一時停止中 (ファイルを持っているあいだ) だけ進捗バーの上に出す。出さない
ときもその行の高さは残し、進捗バーの位置は変わらない (URX44V、2026-09-22 操作者確認)。進捗バーの
左のボタン (3 本線と ▶ の印) は、ファイルを持っているあいだは印が白く、触れるとカーソルをそのファイルへ移す
(ユーザーガイド「RECORDER menu」の Play の f)。持っていないときは [↑] と同じく通常の面のまま印を灰色にし、触れても
何もしない。

再生中はカードの取り出しボタンを使えない (p081-1 は減光した面、p083-1 は通常の面)。Play タブの一覧はフォルダと再生できる
ファイルを並べ、4 トラック以上のファイルは出さない。印はフォルダ、再生できるファイル、再生中と一時停止中のファイル
(スピーカー)。Edit タブは 4 トラック以上のファイルも並べ、`4tr`〜`16tr` で示す (ユーザーガイド「RECORDER menu」の
Play と Edit の List icons)。Play・Edit とも、本体の今のサンプリング周波数と違う周波数で録ったファイルは出さない
(ユーザーガイドの Play の NOTE と、URX44V で 48 kHz の録音が 44.1 kHz ではどちらのタブにも出ず、48 kHz に戻すと出たこと、
2026-09-22 操作者確認)。周波数を切り替えると、一時停止中のファイルも放す (SETUP の Sampling Frequency で同じ日に確認)。
設定ファイルの読み込みで周波数が変わったときも同じにしている。SAVE/LOAD のファイルは、角の折れたページに横線 2 本の印 (p084-1)。

## カードの中身

カードは 3 種類の項目を持つ (`src/model/card.ts`): フォルダー、レコーダーが書いた録音 (`.wav`)、
SAVE/LOAD が書いた設定ファイル (`.urxf`)。並びはフォルダーが先、その中で名前順。出荷時は名前
`test` のカードが入っていて、中身は無い。

録音は [■] でカードに残る。名前は本体の時計から `YYYYMMDD_HHMMSS.wav`、長さは経過時間、
トラック数は [Track Count] の値、置き場所はカード画面が開いているフォルダー。同じ名前が既に
あるときは秒を 1 つずつ進める。1 秒に満たない録音は何も残さない。RECORDER の `Time` 欄は録音の
長さ、SAVE/LOAD の `Date/Time` 欄は書いた日時。

空き容量はカードの容量から中身の合計を引いた値。容量は 128 GB のカードをフォーマットした後の
125,000,000,000 バイト、録音 1 件は 秒数 × 48,000 × 3 バイト × トラック数 (ユーザーガイドの仕様表の
microSD Card Slot: WAV 24-bit)、設定ファイルは 50,668 バイト (設定ファイルはどれもこの大きさ)。
表示は 1024³ で割って小数 1 桁の `116.4GB Free` (p083-1、p087-1)。その上にカードの名前 (フォーマットで付けた
ボリュームラベル) をもう 1 行置き、2 行を右上に x313 から左揃えで出す (x313..387 / y58..81)。どのカードの画面も同じ
位置で (URX44V、2026-09-22 操作者確認)、SAVE/LOAD の p084-1 と TOOLS の p087-1 は 2 行、RECORDER の p081-1・p083-1 は
名前の行が空の図。カードが無いときはこれらの画面を開かず、microSD のトップに移る。取り出しボタンに
触れると、実機と同じく `Now you may safely remove the microSD card.` と [OK] だけのダイアログを出す。
文言は 1 行で、左に丸に i の印、[OK] は右下 (URX44V、2026-09-22 操作者確認)。[OK] でカードを抜いたことにする
([known-issues.md](known-issues.md))。

フォルダーは 1 回目の接触でカーソルが移り、カーソルのある状態でもう一度触れると開く。一覧は
開いているフォルダーの中だけを並べる (ユーザーガイド「RECORDER menu」の File list)。[↑] は
1 階層上へ戻り、根では使えないボタンになる。パス欄は根からの現在位置を出し、収まらないときは
末尾側を見せる (同じ節の Folder name display)。新しいフォルダーと [Save as] の設定ファイルも
開いているフォルダーに作られる。

Edit タブの [Delete] は `Delete the selected file?` を尋ねてから消し、[Rename] と [New folder] は
SCENE の題と同じ入力シートを開く。TOOLS の [Format] はカードを空にする。SAVE/LOAD の [Save] は
選んだ設定ファイルへ今の設定を書き、[Save as] は入力した名前に `.urxf` を付けて書き、[Load] は
選んだ設定ファイルを本体へ戻す。既にあるファイルへ書くときだけ `File alerady exists. Replace it?`
を尋ね、[Load] は尋ねずに実行する。設定ファイルが選ばれていないとき [Save] と [Load] は使えない
ボタンの面になる。設定ファイルが持つのは画面の状態 (`ui.`) とカード自身 (`sd.`) を除く全ての値。

再生は選んだ録音の長さに対して進み、経過時間と進捗バーを 1 秒ごとにその場で書き換える。
終端に達すると経過時間が先頭に戻って止まり、そのファイルは持ったまま。

## 題の入力シート

[Title] と、保存の無い番号の [Store] が開くシートは画面全体を `--dialog-sheet` の面で覆う。左上に [Cancel]、右上に [OK] (DATE / TIME のダイアログと同じ
ボタン)、その間の下に黒い入力欄 (x124..361 / y49..89、題は 15px の太字、右端に消去ボタン)、下端にキーボードを置く。
キーは 4 行 (y96..135・y137..176・y178..217・y219..257) で、1 キーの幅を 4 等分した 40 列に並ぶ (x7..470、キーの間隔
2px、字は 15px)。

| 配列 | 1 行目 | 2 行目 | 3 行目 |
|---|---|---|---|
| 文字 | `qwertyuiop` | 半キー右から `asdfghjkl` | [Shift]、`zxcvbnm`、後退 (2 キー幅) |
| 数字 | `1234567890` | 2 キー目から `-/:;()\&` | [#+-]、3 キー目から `.,?!'`、後退 |
| 記号 | `[]{}#%^*+=` | 2 キー目から `_\|~<>$\"` | [123]、3 キー目から `.,?!'`、後退 |

4 行目は文字・数字・記号の配列で共通の並びで、先頭のキー ([123] または [ABC]、1.5 キー幅)、space (3 キー幅)、`@`、`.`、
`<`・`>` (1.75 キー幅) が続く。[123] は数字、[#+-] は記号、[ABC] は文字の配列に替える。

[Shift] はタップのたびに入れ切りし、入っているあいだ面を `--accent-selected` にして文字のキーを大文字で描き、大文字を打つ。
題は 16 文字まで打て、それを超えるキーは題を変えない。`<` `>` はカーソルを 1 文字ずつ動かし、打った文字と後退はカーソルの位置に効く。消去ボタンは欄を空にする。シートは
文字の配列・Shift を切った状態で開き、[OK] で題を書き込む。欄が空のあいだ [OK] は何もしない。[Cancel] は何も書き込まない。

## フォーカスの枠

実機のつまみで回すコントロールは、触れたもの 1 つだけがフォーカスを持ち、マゼンタ (`--accent-focus`) で示す。画面を
開いた直後と画面を移ったときは、どれも持たない。例外は 3 つ: EQ は最後に選んだバンド (最初は LOW) を持った状態で開き、
このバンドは全チャンネルの EQ で共通で、電源を切る (再読み込みする) まで保つ。1-knob がオンの COMP・EQ 画面は、
レベルにフォーカスを固定した状態で開く (下記)。BRIGHTNESS は回す値が Screen 1 つだけなので、その値を持った状態で開く。

- 値ボックス: 枠と塗り (`--accent-focus-fill`)。ポップアップの画面の値 (DATE / TIME の日時)、HOME のストリップの
  レベル、画面下のノブの読み出し欄には付けない。
- スクロールバー: 一覧か本文、またはバーに触れると縁がマゼンタになる。SCENE LIST、microSD の一覧、LICENSE、
  入力ソースの選択シート、DATE / TIME の TIME ZONE、USER DEFINED KNOBS の割り当ての列 (触れた列だけ)。
  プルダウンの選択肢の一覧とプルダウンの箱には付けない。
- ダイナミクスのつまみと EQ のバンドの輪: 縁と、値の動く向きの両側で点滅する三角 (EQ の LOW と HIGH は左右、LOW MID と
  HIGH MID は上下)。
- チャンネルビューのブロック: 値ボックスに値ボックスと同じ枠 (DELAY も同じ、p098-2 の x405..464 / y92..113)。
  1-knob がオンの EQ はパネルから 1px 離れた枠を付ける (p096-4 の x300..381 / y83..128)。別の値に触れるとフォーカスは
  そちらへ移り、画面に立つ枠は 1 つまで。
- 1-knob がオンの COMP・EQ 画面のレベル: 画面を開いたときから画面を移るまで枠が付く。他のコントロールに触れても
  移らず、画面下のノブの欄を含めて他の値は回らない。

## ボタンの角

ボタンの角は、ブラウザの角丸ではなく決まった画素で描く。半径 4 の角は、3 画素をボタンから抜き、その隣の 2 画素で地を
`--px-cut-out` (40%)・`--px-cut-in` (8%) だけ透かす。色を塗らないので、面が明るくても暗い輪郭が出ず、押し込んで動いても角に
別の色が出ない (押し込み中は足側の抜きが沈んだ分だけ上がり、輪郭は立っているときと同じ)。帯は面を `--px-band-cast` (31%)
だけ落とした色で、面が帯に接する段の角も同じ 2 つの割合で曲がる。3 つの割合は図の実測から採った (面 `(74,81,90)` の帯が
`(49,57,58)`、面 `(132,223,255)` の帯が `(90,158,181)`。角は地がシートのときと黒のときの両方で合わせた)。
[ON] / [CUE] / [PRE] の半径 3 の角は 4 行に 3 つの混色で、面・帯・地の組ごとのトークン (`design-tokens.md` の `--corner-*`)
を使う。USER DEFINED KNOBS のバンクと
SAMPLING FREQUENCY の周波数と CH SETTING の PAN と BAL は 1 本につながった列で、丸いのは列の両端だけ (p057-1、p058-1、p093-1)。エフェクトの Cho・Off・Vib も同じ列で、1 つで立つ Gate と Sync は 4 隅とも同じ画素で丸める。RECORDER の進捗バーの両端と、
再生済みの部分の両端も、12 行の半円を画素で描く (p079-2、p081-1)。

交換 (`--pb-*`) と題札 (`--pt-*`) の角は同じ 46 か所を、それぞれ自分の混色で描く。46 レイヤの並びが 2 つの規則に分かれて
いるのは、1 つの規則が持てるレイヤの並び順が 1 通りだけで、どちらかを並べ替えると隣の角丸のコントロールで画素が動く
ため (実測: ch.eq で 21 画素が各チャンネル ±1、1-knob 点灯時は ch.comp で 3 画素)。並びが一致していることは
`src/style/columns.test.ts` の「the two corner maps」が見る。

箱の角も同じ描き方で、形は箱の種類で決まる。

- 沈んだセル (パラメータのセル・OSC の出力・チャンネルビューの PAN / LEVEL・DELAY のセル・エフェクトのパネル・ダイナミクス画面の設定の行 (p099-1)) とチャンネルビューのブロックは、
  角を 5 画素にわたって地と 3 つの混色で丸める。ブロックの下の角は、帯が地に接する足と、面が帯へ曲がる段の 2 か所を描く
  (p056-1、p090-1)。INPUT のパネルも同じ形で、混色はパネル用の 2 つ (p100-1)。
- 値ボックスと窪み (RECORDER のスロット、SCENE LIST の箱、名前だけの箱) は 3 画素で丸め、窪みは角の内側に
  もう 1 つの混色を置く (p090-1、p067-1、p079-2)。INPUT の値ボックスは混色を置かず、パネルの地だけで 2 段に曲がる (p100-1)。
- フォーカス中の値ボックスは 1px の枠を角まで回し、枠と地・枠と塗りの混色で曲がる (p090-1、p100-1)。
- EQ・GATE・COMP・DUCKER のグラフの枠は、角を 3 画素にわたって地と 2 つの混色で丸め、混色を枠の上に重ねる (p106-1、p099-1、p114-1)。
- カードのパス欄 (SAVE/LOAD、RECORDER の Play / Edit) は右の 2 隅を 3 画素で丸め、左の 2 隅は隣の窪みと接する 1 画素の混色に
  する (p084-1、p081-1、p083-1)。SETUP の GENERAL のトレイは 4 隅を 5 画素にわたって地と 4 つの混色で丸める (p041-1)。
- 右下のノブ切り替えボタンの左上の角と、ノブ読み出しバーの上の 2 つの角は、2px の縁が角で太る形を画素で描く
  (p045-1、p056-1、p038-4)。
- シートの戻るボタンは、左下の角を `--sheet-back-corner-*`、右上の角を `--sheet-back-top-corner-*` で描く
  (p100-2。「画面に重なるシート」)。
- 選ばれていない HOME のストリップは、名前の帯の上の角を一段明るい面の混色で、下の角を色帯の色で丸める。帯の足は色帯を
  ガラスに 36% / 74% / 80%、側面を上る段は面に 100% / 92% / 60% / 23% / 18% で混ぜた色 (p047-1 の 3 本で同じ比)。
  選ばれたストリップは枠が曲線で回るので、角は丸めた箱のまま。MONITOR のストリップは見出しの上の角と、帯のある下の角を
  同じ形で描く (p067-1)。

色は `design-tokens.md` の `--corner-sunk-*`・`--corner-block-*`・`--corner-well-*`・`--corner-focus-*`・`--corner-toggle-*`・
`--corner-readout-*`・`--corner-raised-*`・`--corner-mon-*`・`--corner-panel-*`・`--corner-plot-*`・`--corner-path-*`・`--corner-tray-*`。

## ドロップダウン

値を選ぶ箱 (CH SETTING の Signal Type / Rec Point / COMP・EQ、SETUP の User Defined Knobs や
Date/Time の書式、Software Integration の送り先、COMP の Knee、DUCKER の Ducker Source、
DELAY の Frame rate) はタップで候補の一覧を画面上に開き、選ぶと閉じる。タップごとに値が
1 つ送られる動作ではない。ガラスに載る候補は 5 つまでで、それより長い一覧は実機が長い一覧を
開くシートの上に開く (DUCKER の Ducker Source と DELAY の Frame rate がこれに当たる)。

一覧のパネルは選択肢を上下左右とも 4px 内側に置き、選択肢どうしの間も 4px 空ける (p079-3 実測:
パネル y54..233、最初の札 y58、最後の札の下端 229)。

箱は面が `--surface`、下端 3px が影の帯、左の余白 12px。右端の 6px 内側に 9x8 の白い下向き三角が
立ち、先端の 1 行は 1px 幅 (p092-1・p099-1 実測)。COMP の Knee は右端から 10px 内側 (x399..407)。

画面ごとに違う箱と印は次のとおり。

- DELAY の Frame rate: 9x6 の `--drop-mark` (p115-1)。
- Date/Time の書式: 10x6 の `--drop-mark`、右端から 12px (date) と 13px (time) 内側 (p064-1 の x246..255 と
  x344..353 / y209..214)。箱は下端 4px が帯で、date の箱は x144..267。
- Software Integration の送り先: 10x6 の白、右端から 11px 内側 (p065-1 の x265..274)。箱は高さ 40px、
  2 つの行は 11px 空け、値は左端から 16px。

一覧は箱の真下に開き、画面の端に掛かるときは内側へ寄せる。画面より縦に長い一覧は
スクロールする。閉じるのは項目のタップ・一覧の外のタップ・`Escape` の 3 つで、画面が
切り替わったときも閉じる。実装は `src/ui/widgets.ts` の `openOptions()` 1 箇所で、
`pulldown()` (値を表示する箱) と `dropdown()` (設定名を表示する箱) が共有する。

## HOME ストリップの送りのつまみ

ストリップ下端のつまみは、[Sends] が表示している送り先への送りレベルを回す (ユーザーガイド
「Channel area」の g)。STEREO はチャンネル自身のフェーダーが送るので、そこではフェーダーが立つ
(p047-1 は工場出荷のフェーダーの `0.00`、p157-1 は MIX 1 への送りの `-∞`)。[Sends] のタブは
送り先を STEREO だけ短く `ST` と書き、番号のあるバスは空白を入れて `MIX 1` と書く (p047-1、p157-1)。

SEND TO 画面でその送りが切になっているとき、つまみの面と点灯した弧は `--send-off`、値は
`--send-off-ink` にする。値は回せるままで、回しても送り先へは出ない。値だけ明るいのは、読める
必要があるため (`--surface-well` に対して 4.5:1)。

## HOME ストリップの構成

選択中のストリップの枠は箱の**外側**に 2px で立つ (p047-1 実測)。非選択時 8px あるストリップ間の
隙間のうち手前 2px を占め、画面端のストリップでは main 領域の外側の 2px の余白 (左端 x0-1、
上端 y48-49、下端 y270-271) にも出る。`.main` はこの分だけ外へはみ出させる
(`overflow: clip` + `overflow-clip-margin`)。ストリップ自身は枠線を持たず、内側の余白は
`padding` が作る。

選ばれていないストリップの角は、[ボタンの角](#ボタンの角) の画素の並びで描く。選ばれたストリップは枠が曲線で回るので、
専用の半径 (`--radius-strip`、実機の角に円を当てると 5.98px なので 6px) の丸めた箱のまま。

ストリップ下端のカラーレールは箱の端まで届き、外枠と隙間なく接する (p045-1 / p047-1 実測)。
太さはストリップ中央で 4.0px (実測) で、両端では角に沿って上へ回り込む。選ばれていないストリップでは、回り込みを
レールの色を面とガラスに混ぜた画素で描き、レール自体はその下の層に置く。選ばれたストリップでは
「ストリップの輪郭をレールの太さぶん持ち上げた帯」として描く (角丸を持つ枠の内側に `box-shadow: inset 0 -4px`)。
レールの色はストリップのチャンネルカラーで、`--rail` カスタムプロパティで渡す。

ストリップの中身の高さと間隔も実機の実測値に合わせてある。1 本 220px (メインエリアの高さ) の
内訳は次のとおりで、左右の余白は 6px。

| 行 | 高さ | 直前の間隔 |
| --- | --- | --- |
| 名前パネル (`--surface-raised` の帯。ストリップの端まで届く) | 36 | — |
| インジケーターとメーター | 69 | 6 |
| ON / CUE (各 40 角、間隔 6) | 40 | 7 |
| PAN スライダー | 4 | 9 |
| レベル (ロータリー 38 角と値表示 38x22) | 36 | 5 |
| 下端の余白 (下 4px はレールが重なる) | 8 | — |

インジケーターの行は左詰めではなくブロックいっぱいに散らし、GATE を持つ行は 1px 下に置く (p047-1 の HPF / GATE は
y115..123)。名前パネルの 2 行は右端を x94 に揃える (p047-1)。ブロックとメーターは 4px 空け、
メーターはモノラルでも 2 レーンぶん (8px) 場所を取るのでブロックは 74px。

ステレオの入力の名前の 1 行目は `CH 5/6` と両方の番号を書き、チャンネルの画面が開かないほうの番号を `--strip-id-other` で描く
(2 行目は変わらない)。名前の欄をタップすると開くチャンネルが入れ替わり、ストリップの選択は変わらない。チャンネルの画面の
`‹` `›` で送ったチャンネルも HOME に残る。FX・MIX・STEREO・STREAMING には開くチャンネルを選ぶ手段が無く、HOME からは L を開く。
インジケーターの行のタップはストリップを選び、選ばれているストリップではチャンネルビューを開く。

STREAMING のストリップは [ON]・PAN スライダー・レベルを持たず、[CUE] だけを右半分に置く
(p048-5)。マルチファンクションノブも STREAMING の位置には何も割り当てない。

ON / CUE は下端 4px が自分の色の暗い影になる (実機の CUE は面 (214,206,214) に対し影が
(156,150,156) で、黒 27% を重ねた値)。枠線ではなく内側の影として描く。レベルの値表示は
角丸 4px の箱に中央揃えで、実機も値の左右の余白が揃う。

値の箱はロータリーが残した幅そのもので、値の文字数では変わらない。HOME を写したキャプチャのうち
箱がユーザーガイドに載っているもの (p036-1・p045-1・p047-1・p051-4 の 4 本、p048-1・p048-2・p048-4・
p048-5・p049-1 の 1 本目、p048-3 の 2 本目) を当たると、箱はどれも x56..93 の 38px (2 本目からは
106px ずつ右) で、`0.00` も `-5.20` も同じ箱に入っている (p045-1)。6px の内側余白 + ロータリー 38 +
10 + 箱 38 + 6px でストリップの 98px になる。

フェーダーの値は -10 dB 以下で小数第 1 位までになる (`-10.0` / `-25.6` / `-96.0`)。上は
`10.00`、下は `-∞` で、travel が止まるどの値も 5 文字に収まるので、箱の幅を文字数で
変える必要がない。

文字は名前の 2 行目・ON / CUE・レベルの値が `--fs-lg`、名前の 1 行目 (チャンネル番号) が 12.5px、インジケーターのバッジが 12.5px
(実機ではそれぞれ約 9px と、その 1 段下の高さで並ぶ)。

`src/style/columns.test.ts` の「the rows a HOME strip is cut into」が高さの内訳と文字の
大きさを固定している。

## チャンネルバンクの構成

実機の HOME で確認した内容 (URX44V、2026-09-04)。ツールバーの INPUT / OUTPUT ボタンは
バンク一覧を開き、一覧から表示するバンクを選ぶ。ボタン 1 タップでバンクが 1 つ進む経路は無い。
ユーザーガイド p47 は「ツールバーのバンク選択ボタンをタッチ」でバンクが切り替わるとだけ書いている。

| 側 | バンク | 並ぶストリップ |
| --- | --- | --- |
| INPUT | 1 | CH 1, CH 2, CH 3, CH 4 |
| INPUT | 2 | CH 5/6, CH 7/8, CH 9/10, CH 11/12 |
| INPUT | 3 | FX1, FX2 |
| OUTPUT | 1 | MIX 1, MIX 2, STEREO, STREAMING |

バンク一覧の見出しはバンクに並ぶ番号の範囲で、`CH 1 - 4`・`CH 5 - 12`・`FX 1 - 2` と書く (URX22 は `CH 1 - 6` と
`CH 7 - 10, FX 1 - 2`)。出力側は `MIX, ST` と `STREAMING` の 2 行。

バンクボタンの中の印はバンク 1 つにつき 1 個で、表示中のバンクの印だけ他より広い (表示中 25px、ほかは 14px、
間隔 6px、高さ 15px、INPUT 側で表示していない印は `--accent-bank-cell`、p047-1)。名前の右の下向きの印は
9x6 の三角を画素で描き (`--drop-mark`)、[Sends] の印も同じ形。ただし
バンクが 2 つしかない側 (URX22 の INPUT は CH 1・CH 2・CH 3/4・CH 5/6 と CH 7/8・CH 9/10・FX1・FX2
の 2 バンク) では両方とも同じ幅で、行を半分ずつ分ける。バンクが 1 つの側 (OUTPUT) では、印をボタンの左右の端から
同じ 24px の位置に置く。

`src/model/units.ts` のストリップ一覧と `STRIPS_PER_BANK = 4` がこの並びを作る。
`src/model/units.test.ts` の「lays the URX44V banks out the way the unit does」が固定している。

一覧は `INPUT` と `OUTPUT` の帯で 2 つに分かれ、項目名はバンクの中身から作る (`bankName`)。
URX44V では `CH 1 - 4` / `CH 5 - 12` / `FX 1 - 2` と、2 行に分かれる `MIX, ST` + `STREAMING` の 4 つ。
項目名は HOME のバンクボタン (p047-1) と同じ白で、表示中のバンクだけ黒。
一覧の外側には、[Sends] の一覧と同じく HOME (シーン名の箱・ツールバーのアイコン・右の列) を暗くして透かし、
一覧を開いたバンクボタンだけを明るいまま残す。暗い部分は触れても働かず、閉じる操作はバンクボタンの再タップ・
表示中のバンクの項目・一覧の外側の暗い部分のタップの 3 つ (`Escape` はどの画面でも戻る操作)。外側の見え方と、
暗い部分のタップで閉じることは実機で確かめた (URX44V、2026-09-22 操作者確認)。

p48 系の図 (p048-1 から p048-6) は、ユーザーガイドにはキャプチャの一部だけが載っている。載っている
範囲は p048-1・p048-2・p048-4・p048-5 が x0..101 / y49..271 (1 本目のストリップ)、p048-3・p048-6 が
x106..207 / y49..271 (2 本目のストリップ) で、y49 より上のツールバーは含まない。抽出したファイルは
この範囲の外にツールバーと他のストリップも持ち、p048-1・p048-2・p048-3・p048-4・p048-6 の
ツールバーには HOME のアイコン列 (SETUP / microSD / MONITOR / HOME) に無いアイコンが
x265..284 / y11..30 にある。範囲の外の画素は実装の根拠に使わない。

ユーザーガイドの「Channel view variations」の図 (p048-3) に載っているのは
x106..207 / y49..271 の FX1 のストリップ 1 本で、PAD ストリップは載っていない。抽出したファイル
p048-3 はこの範囲の外に PAD ストリップ (名前のインクは x74..95 / y56..80) を持つ。実機の 3 番目の
バンクは FX 1 と FX 2 で、PAD は HOME のストリップに出ない。

URX44 は URX44V と同じ入力ストリップを持つので同じ 3 バンク、URX22 はモノラルチャンネルが
2 本少ないため 2 バンクになる。これは確認した「1 バンク 4 本」から導いたもので、実機で読んだのは
URX44V の並びのみ。
